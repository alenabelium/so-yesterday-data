# You're paying rent on agents when you should start be asking which work should exist.

## Executive Summary

The video argues that the rising costs of AI agents stem not from model pricing alone, but from inefficient legacy workflows that are merely automated rather than redesigned. By starting with a 'blank sheet' approach to business processes, organizations can eliminate unnecessary handoffs and administrative overhead that no longer serve a purpose in an AI-native environment. This strategic redesign allows for the use of cheaper, specialized models for routine tasks while reserving expensive frontier models only for complex exceptions, thereby achieving significant cost savings without sacrificing capability.

## Key Points

- Automating existing legacy workflows with agents often just speeds up inefficient processes; instead, businesses must redraw the path to value by asking which work actually needs to exist before implementing AI solutions. [00:10:12](https://www.youtube.com/watch?v=eLpRDIvOMEw&t=612)
- Implementing a classifier system allows companies to route 99% of routine enterprise work to affordable open-weight models while reserving expensive frontier models only for the difficult 1% of edge cases requiring deep investigation. [00:21:26](https://www.youtube.com/watch?v=eLpRDIvOMEw&t=1286)
- Effective AI adoption requires building a 'thick harness' of structure and tools around cheaper models for predictable tasks, while using a 'thin harness' that gives frontier models the freedom to solve complex problems without restrictive constraints.
