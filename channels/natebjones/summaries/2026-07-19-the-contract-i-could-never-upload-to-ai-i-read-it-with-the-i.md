# The Contract I Could Never Upload to AI? I Read It With the Internet Off.

## Executive Summary

The video argues that local, offline AI models offer a secure alternative to cloud-based AI for processing sensitive documents, addressing critical data privacy concerns. By using tools like LM Studio and open-weight models, individuals and enterprises can scan and mask private information without risking data leaks to external providers. The presenter demonstrates this capability by successfully identifying and masking confidential data in a contract while completely disconnected from the internet. This approach democratizes enterprise-grade security strategies, allowing users to maintain control over their proprietary and personal data.

## Key Points

- Cloud AI models can inadvertently leak data even when instructed not to, as demonstrated by a recent Grok incident where a repository was uploaded despite explicit instructions, highlighting the need for hard guardrails like air-gapping. [00:03:39](https://www.youtube.com/watch?v=5slsNizN6MQ&t=219)
- The presenter demonstrates using LM Studio with the GPT-OSS Safeguard 20B model to scan a contract for private information while offline, successfully masking PII, financial data, and API keys without false confidence. [00:05:31](https://www.youtube.com/watch?v=5slsNizN6MQ&t=331)
- Enterprises are adopting similar strategies using Low-Rank Adaptation (LoRA) to fine-tune models on proprietary data within secure boundaries, such as Azure, ensuring data never leaves the controlled environment. [00:08:45](https://www.youtube.com/watch?v=5slsNizN6MQ&t=525)
- While local AI is free and effective for individuals, companies must be cautious of vendor lock-in when using cloud services like Microsoft's LoRA training, balancing security needs with strategic vendor dependencies.
