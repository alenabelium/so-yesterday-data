# The end of git? OpenAI CTO on the future of coding.

## Executive Summary

OpenAI's CTO discusses how AI agents have transformed coding at OpenAI, leading to a 17x increase in token usage and a need to replace Git with a new repository system designed for always-online agents. He also shares insights on reaching the next billion ChatGPT users through voice-first interfaces and how leaders can prototype ideas directly with AI tools. The conversation highlights the second-order bottlenecks in CI/CD, code review, and infrastructure that arise when code becomes cheap to produce.

## Key Points

- OpenAI's token usage at Frontier Labs increased 17x in the last year, while regular software companies saw only 2x growth, indicating a massive shift in AI adoption and productivity. [00:01:46](https://www.youtube.com/watch?v=S6SEgMooZpE&t=106)
- Git is being replaced internally because it was designed for offline use, whereas AI agents are always online, requiring a new repository system built for higher throughput and constant connectivity. [00:04:31](https://www.youtube.com/watch?v=S6SEgMooZpE&t=271)
- The next billion ChatGPT users will likely interact via voice, not text, because typing in many languages is difficult and voice is more natural, especially in regions like India. [00:09:48](https://www.youtube.com/watch?v=S6SEgMooZpE&t=588)
