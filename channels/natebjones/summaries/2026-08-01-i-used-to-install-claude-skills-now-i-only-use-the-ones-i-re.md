# I Used To Install Claude Skills. Now I Only Use The Ones I Rebuild. Here's Why.

## Executive Summary

The video argues that AI skills should be treated as executable instructions for agents rather than static applications to be collected. It highlights the risks of installing unvetted skills from the internet, which can introduce security vulnerabilities and context bloat. The core thesis is that skills must be rebuilt or customized to ensure they are readable by humans for auditing and optimized for agent execution. Finally, the speaker introduces tools to help users build and audit these skills effectively.

## Key Points

- Skills are not apps but dynamic instructions that load contextually, meaning vague descriptions or bloated files can confuse agents and waste context windows [00:02:12](https://www.youtube.com/watch?v=up0Bsf3f0Xc&t=132).
- Users should avoid blindly installing skills from GitHub as 'Pokémon cards' because untrusted sources pose security risks and often fail to integrate well with existing workflows [00:01:24](https://www.youtube.com/watch?v=up0Bsf3f0Xc&t=84).
- Effective skills require a dual-audience design: clear enough for humans to audit the underlying logic, yet precise enough for agents to trigger and execute reliably [00:03:06](https://www.youtube.com/watch?v=up0Bsf3f0Xc&t=186).
- Advanced users should regularly audit their skill libraries to resolve conflicts between multiple skills that can degrade AI performance over time [00:13:47](https://www.youtube.com/watch?v=up0Bsf3f0Xc&t=827).
