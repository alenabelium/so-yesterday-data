# Stop Paying $200 For Work An $18 Model Can Do Inside Claude Code And Codex.

## Executive Summary

The video argues that developers can significantly reduce AI coding costs by using the affordable GLM 5.3 model within established harnesses like Claude Code and Codex, rather than relying solely on expensive premium subscriptions. It emphasizes the critical distinction between the AI model, the coding tool (harness), project context, and conversation history to avoid hidden costs associated with switching providers mid-session. The core strategy involves using cheaper models for bounded tasks with clear definitions of done while reserving powerful models for complex investigation and decision-making.

## Key Points

- Distinguishing between the model, harness, context, and conversation is vital because switching models mid-session often loses prompt caches and conversation history, leading to higher effective costs than expected [00:04:24](https://www.youtube.com/watch?v=4HvFqhtCb-A&t=264).
- To use GLM 5.3 in Claude Code or Codex without losing your setup, configure a separate profile or session that loads the same project files and hooks but uses a new API key and provider address [00:11:15](https://www.youtube.com/watch?v=4HvFqhtCb-A&t=675).
- When moving work between models, create an explicit 'handoff file' detailing goals, current state, constraints, and tests to ensure the new model has sufficient context without pasting entire conversation histories [00:09:58](https://www.youtube.com/watch?v=4HvFqhtCb-A&t=598).
- Use cheaper models for tasks with clear definitions of done and robust test suites, while keeping stronger models for complex root-cause analysis or ambiguous problems requiring nuanced judgment [00:14:04](https://www.youtube.com/watch?v=4HvFqhtCb-A&t=844).
