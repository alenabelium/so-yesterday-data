## Wider context

OpenAI's emphasis on agentic features—computer use, tool search, long-running tasks—signals a deliberate pivot toward building the substrate for autonomous agents, likely an OpenAI version of OpenClaw. This release highlights a philosophical divergence: OpenAI optimizes for pipeline execution and completeness, while Anthropic focuses on judgment and usability. The thinking/auto mode gap underscores a critical usability challenge as models become more powerful.
