## Headline takeaway

Salesforce Headless 360 and ChatGPT Workspace Agents redefine the agent race as an infrastructure play, not a model-quality contest.

## Tools covered

### ChatGPT Workspace Agents
- **Vendor**: OpenAI
- **Category**: agent
- **Timestamp**: [04:21](https://www.youtube.com/watch?v=dQK_pTXrGDk&t=261)
- **Why It Matters**: Shared, cloud-run agents for teams that work across Slack and ChatGPT, built for repeatable workflows like feedback routing or metrics reporting. Marks a shift from personal assistants to reusable team work units.
- **Sota Comparison**: Strong for cross-tool recurring workflows, but not a universal replacement; data access depends on connectors.
- **Sota Band**: inferred
- **Access Constraint**: Available in ChatGPT and Slack

### Salesforce Headless 360
- **Vendor**: Salesforce
- **Category**: agent
- **Timestamp**: [05:36](https://www.youtube.com/watch?v=dQK_pTXrGDk&t=336)
- **Why It Matters**: Exposes all Salesforce capabilities as APIs, MCP tools, and CLI commands, letting any agent reach CRM data directly. Aims to make Salesforce infrastructure under the agent economy, not just another agent product.
- **Sota Comparison**: Scores extremely well on the five-question filter: plugs into existing systems, open to other agents, owns key data, has ecosystem, and is stackable.
- **Sota Band**: beats
- **Access Constraint**: Announced at Trailblazer DX

### Microsoft Copilot Wave 3
- **Vendor**: Microsoft
- **Category**: agent
- **Timestamp**: [08:26](https://www.youtube.com/watch?v=dQK_pTXrGDk&t=506)
- **Why It Matters**: Introduces Copilot Co-Work for long-running multi-step agents and Work IQ for deep data access inside Microsoft 365. Strong for Microsoft-native enterprises but weaker on openness to external agents.
- **Sota Comparison**: Strong on data access and governance for 365 shops; weaker on external composability and coding workflows.
- **Sota Band**: inferred
- **Access Constraint**: Microsoft 365 native

### Kimi K2.6
- **Vendor**: Moonshot
- **Category**: agent

- **Sota Comparison**: Technically impressive with strong benchmarks, but lacks the enterprise data and connector story of Western infrastructure plays.
- **Sota Band**: inferred

### Perplexity Personal Computer
- **Vendor**: Perplexity
- **Category**: agent
- **Timestamp**: [13:39](https://www.youtube.com/watch?v=dQK_pTXrGDk&t=819)
- **Why It Matters**: Mac rollout adds local file editing, computer use, and browsing, turning it into a digital worker for research-heavy tasks that produce polished artifacts.
- **Sota Comparison**: Strong for research and artifact creation; weaker for team-shared recurring processes or deep enterprise integration.
- **Sota Band**: inferred
- **Access Constraint**: Mac app with local access



## Wider context

The agent race has shifted from model quality to infrastructure: the launches that matter are those that change what existing tools can reach and how easily systems stack. Salesforce Headless 360 and Microsoft Copilot Wave 3 exemplify this by exposing data and workflows as APIs, while open-weight models like Kimi K2.6 signal a growing self-hosted alternative. The key is layering, not switching—choose wrappers that own the data fabric, and route work by task shape.
