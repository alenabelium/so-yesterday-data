## Thesis

The agent war is won not by form factor—computers, memory, background work—but by utility, which depends on model quality and task-specific competencies, making some agents worth $100 a month and others not.

## Argument

The mechanism is utility, not form factor. Every agent now ships with a computer, memory, and background work, so those features are table stakes. What differentiates them is the model behind the agent and the specific tasks it excels at. Muse is great for practical, low-intelligence chores like calls and small purchases; Instinct is proactive around travel and restaurants; Dots is built for serious work, leveraging the context you've built in ChatGPT. This is why I argue that utility does not converge even as form factors do.

OpenAI's bet is that context becomes intelligent. Dots uses your ChatGPT memories and connected apps to proactively fix your calendar or adjust launch materials when a feature slips. The value is in understanding what promises depended on a changed feature and having an always-on agent that can read, respond, and prepare adjustments. That's where Dots shines, and it's why OpenAI paired it with their most powerful model, Astra.

But the real long-term play is Spaces and Pages, which turn ChatGPT into a collaborative workspace—a direct competitor to Microsoft Office. This assumes an AI-native, AI-literate organization, which I rarely see outside Silicon Valley. Microsoft has a natural trust advantage, but the 'no one got fired for buying Microsoft' argument won't hold if Spaces delivers a fundamentally better way to work.

For individuals, the decision to pay $100 is economic: does it save time or money? Soul 6.1 is the unsung hero, delivering near-Astra quality at a fifth of the cost, so you can do more without exhausting limits. I wouldn't upgrade

## Counterpoints

- OpenAI's Dots looks like Grok's bot, sparking a Twitter spat, but the host argues this misses the point: form factor similarity doesn't mean utility similarity.
- Spaces and Pages assume AI-native, AI-literate organizations, which are rare outside Silicon Valley; Microsoft has a trust advantage, but the 'no one got fired for buying Microsoft' argument won't hold.
- Current $200 subscribers will see their limits reduced after October 29th, which was unpopular; the host notes people want more AI, not less, regardless of model efficiency.
- Dots doesn't instantly know everything from ChatGPT; it only accesses memories you choose to share, which is a privacy choice that builds trust but limits proactive capabilities.
- The $500 Pro Max plan with ultra-fast Astra can generate wrong answers quickly, so it's only worth it if you have the skill to manage it effectively.
