## Thesis

The agent war is about utility, not form factor, and Dots is worth $100/month only if you can make that money back.

## Argument

The form factor for agents is converging—everyone has a computer, memory, and background work. But utility diverges because the underlying model and configuration differ. Muse is great for practical tasks like calls and purchases; Instinct targets travel and restaurants. Dots is built for work, leveraging the context you've built in ChatGPT. The real value is in the outcome: a proactive agent that fixes a zombie meeting or resolves a DMV dispute saves time and money. OpenAI's bet is that more of your work stays in ChatGPT, and the efficient Soul 6.1 model lets you do more without exhausting limits. Spaces and Pages are a direct challenge to Microsoft, but they assume an AI-native organization that few companies have. The $200 plan change is a warning: you're getting less for the same price. So, don't upgrade just for Dots—upgrade if you have a plan to get a return on that $100. The future is about outcomes, not activity, and that's the trillion-dollar question.
