## TL;DR

As AI agents become the primary interface for software, the traditional app era is ending. The new battleground is a three-layer stack—data, application, and agent—where value shifts to data layers and agent gateways. Buyers and sellers must navigate this stack to avoid vendor lock-in and capture future value.

## The argument

### Define the Three-Layer Stack
- **Anchor Timestamps**: ['00:23:58']
- **Claim**: Software is now a three-layer stack: the data layer (who provides the data), the application layer (the interface and workflows), and the agent layer (the AI that acts on data). Understanding your position in each layer is essential for both buyers and sellers.
- **Role**: definition

### Data Layer Becomes the Moat
- **Anchor Timestamps**: ['00:07:43']
- **Claim**: In the agent era, the data layer is the most defensible part of the stack. Companies like Meta and Salesforce are positioning their data as critical for agents, making it harder for customers to switch vendors. The agent needs the data, so whoever controls the data controls the relationship.
- **Role**: evidence

### Application Layer Decomposes into Interfaces and Workflows
- **Anchor Timestamps**: ['00:27:17']
- **Claim**: The application layer isn't dead, but it splits into interfaces and workflows. Interfaces may change or disappear, but structured workflows—like payroll compliance—remain valuable. Companies that provide these workflows can thrive even if users never open their app.
- **Role**: synthesis

### Agent Layer Demands Flexibility and Choice
- **Anchor Timestamps**: ['00:16:26']
- **Claim**: The agent layer is where buyers seek flexibility to avoid lock-in. Salesforce's partnership with Claude and its agent control panel exemplify this: offering multiple agents and models makes the value proposition stronger. Sellers must provide choice to win buyers.
- **Role**: evidence

### The Counter: Why the App Era Isn't Over
- **Anchor Timestamps**: ['00:28:26']
- **Claim**: Despite the shift, the application layer persists because many workflows are too complex or compliance-heavy to replace. Workday and ADP show that structured workflows on top of data remain essential. The interface may change, but the underlying workflow value endures.
- **Role**: counter

## Evidence and caveats

DoorDash's text-based ordering and MCP server show how losing the interface doesn't mean losing the transaction. Crust Data's case study demonstrates a two-person recruiting firm building its own skill on top of a data API, bypassing traditional SaaS tools. Workday's payroll agent relies on customized data and company rules to handle compliance. Caveats: The speaker notes that agents are still improving, and the competitive landscape is complex. He also acknowledges that not everyone will use command lines, and that some workflows are too risky to automate. The recruiting story is anonymized, and the speaker admits that individual AI usage patterns are idiosyncratic, making vendor changes difficult.
