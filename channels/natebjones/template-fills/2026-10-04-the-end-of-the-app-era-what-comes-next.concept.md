## TL;DR

As AI agents become the primary interface for software, the traditional app-centric model is giving way to a three-layer stack: data, application, and agent. This shift forces buyers and sellers to rethink value, moving from selling applications to selling data layers, workflows, and agent gateways. Understanding this new structure is crucial for navigating the changing software landscape and avoiding vendor lock-in.

## The argument

### The App Era's Decline
- **Anchor Timestamps**: ['00:00:51']
- **Claim**: As agents take over tasks like reading contracts and creating launch plans, the traditional software tools that once performed these functions become less indispensable. The value shifts from the application itself to the trained agent and the accumulated knowledge, making it harder to replace the agent than the software.
- **Role**: definition

### The Three-Layer Stack Emerges
- **Anchor Timestamps**: ['00:23:58']
- **Claim**: Software is now understood as a three-layer stack: the data layer (who provides the data), the application layer (the interface and workflows), and the agent layer (the AI that acts on the data). Each layer has distinct value and strategic importance, and companies must position themselves within this stack to remain relevant.
- **Role**: definition

### Data and Distribution as Strategic Moats
- **Anchor Timestamps**: ['00:09:47']
- **Claim**: Companies like Salesforce and Microsoft leverage their existing data and distribution to build agent gateways and control planes. They offer a reliable platform for agents to interact with data, making them indispensable even as the interface shifts. This strategic position is more robust than simply offering an application.
- **Role**: evidence

### The Counter: Applications Aren't Dead
- **Anchor Timestamps**: ['00:27:17']
- **Claim**: The application layer isn't dead; it's being decomposed into interfaces and workflows. Structured workflows, like those in payroll, remain highly valuable and compliant. The interface may change, but the underlying workflow logic and data structure become the enduring value proposition.
- **Role**: counter

### The New Imperative: Vertical Integration
- **Anchor Timestamps**: ['00:35:23']
- **Claim**: Agents force a vertical integration of the stack, making everyone a decision-maker. Individuals, buyers, and sellers must understand how data, application, and agent layers interact to achieve results. This holistic view is essential for navigating the future of software and avoiding being trapped by vendor lock-in.
- **Role**: synthesis

## Evidence and caveats

Examples include DoorDash's agent-based ordering and MCP server, Salesforce's Koa reasoning model, and Microsoft's Autopilot. The recruiting story illustrates how a data provider (Cross data) can move up the stack by enabling customers to build workflows. Caveats: The speaker notes that not every company needs to build its own agent; providing an MCP server is a minimum requirement, but differentiation requires more. He also warns that individual AI usage patterns are idiosyncratic and must be shared to avoid productivity loss during vendor changes.
