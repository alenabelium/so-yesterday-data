## TL;DR

Software is splitting into data, workflow, and agent layers. Buyers and sellers must navigate this new stack because agents are becoming the primary interface, and whoever controls the data and agent gateway holds the power.

## The argument

### Define the three-layer stack
- **Anchor Timestamps**: ['00:23:58']
- **Claim**: The common thread across all software is a three-layer stack: the data layer (who provides the data), the application layer (the interface and workflows), and the agent layer (the AI that acts on data). Every company and employee must understand their position in this stack.
- **Role**: definition

### Meta and Salesforce show the data-layer play
- **Anchor Timestamps**: ['00:07:43', '00:09:47']
- **Claim**: Meta's Muse for Small Business connects to business data (Shopify, QuickBooks) to become a business headquarters. Salesforce leverages its 20 years of CRM data to build Koa, a reasoning model trained on synthetic data, positioning itself as both a data layer and an agent gateway.
- **Role**: evidence

### Microsoft and DoorDash show the agent-gateway play
- **Anchor Timestamps**: ['00:13:23', '00:17:29']
- **Claim**: Microsoft stacks data (Azure), workflows (Office), and agents (Copilot, Autopilot) to be the trusted AI provider. DoorDash, though not SaaS, shows the future: its MCP server and text ordering mean you never open the app, but DoorDash still wins the transaction — the agent gateway is the new moat.
- **Role**: evidence

### The counter: workflows still matter
- **Anchor Timestamps**: ['00:22:27', '00:27:17']
- **Claim**: The application layer is not dead — it decomposes into interfaces and workflows. Payroll (Workday, ADP) is a structured, compliant workflow that agents make more valuable, not replace. Buyers still need confidence in the underlying workflow's reliability, not just the agent.
- **Role**: counter

### Synthesis: the keys to the kingdom
- **Anchor Timestamps**: ['00:25:58', '00:31:55']
- **Claim**: The winning position is to control the data layer and offer a flexible agent gateway, while providing workflows that are plug-and-play for AI. Buyers must ask: have you figured out the data layer, is the application layer appropriate, and does the agent layer give us flexibility? That's the keys to the kingdom.
- **Role**: synthesis

## Evidence and caveats

Cross data's case study: a two-person recruiting firm built its own skill on Cross data's API instead of buying a recruiting SaaS — showing data providers can move up the stack. Workday's payroll agent uses company rules to identify issues, but someone still maintains records and approves — agents help with complexity, not replace compliance. Salesforce's Koa is in pilot and trained on synthetic data, not real customer data. DoorDash's MCP is a limited beta. Microsoft's Autopilot is in preview. Caveat: the host notes that if two providers offer equally good data and execution, agents make switching easier — so data alone isn't a moat.
