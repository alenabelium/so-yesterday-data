## TL;DR

Software is shifting from selling applications to selling data layers, workflows, and agent gateways. As AI agents become the primary interface, the value moves to structured data and the workflows built on top. Buyers and sellers must understand the new three-layer stack—data, application, and agent—to navigate the changing landscape.

## The argument

### The Agent Interface Displaces the App
- **Anchor Timestamps**: ['00:00:00']
- **Claim**: DoorDash's text-based ordering shows how agents become the primary interface, making the app itself less indispensable. In business, agents reading contracts and emails replace direct tool use, shifting value from the application to the agent's learned context.
- **Role**: definition

### Data and Workflows Become the New Moat
- **Anchor Timestamps**: ['00:02:00']
- **Claim**: A recruiting tool's value shifts from its interface to its data and the agent's trained workflow. The company still gets paid for data, but the agent's personalized context makes it harder to replace, creating a new kind of lock-in.
- **Role**: evidence

### SaaS Giants Reposition as Agent Gateways
- **Anchor Timestamps**: ['00:09:47']
- **Claim**: Salesforce, Microsoft, and Meta are all positioning themselves as data layers and agent gateways, not just app providers. Salesforce's Koa model and Microsoft's Autopilot show how incumbents leverage data and distribution to control the agent layer.
- **Role**: evidence

### The Application Layer Isn't Dead—It's Decomposed
- **Anchor Timestamps**: ['00:27:17']
- **Claim**: Applications split into interfaces and workflows. Workday's payroll agent shows that structured workflows on top of data remain valuable, even if the interface changes. The application layer persists as a source of compliance and reliability.
- **Role**: counter

### Everyone Must Think in Three Layers
- **Anchor Timestamps**: ['00:35:23']
- **Claim**: Individuals, buyers, and sellers must all understand their position across data, application, and agent layers. Agents force vertical integration of the stack, making everyone a decision-maker and requiring clear communication about how AI is used.
- **Role**: synthesis

## Evidence and caveats

Examples: DoorDash's text ordering and MCP server; Salesforce's Koa reasoning model; Microsoft's Autopilot; Crust Data's API-based recruiting skill; Workday's payroll agent. Caveats: Salesforce's Koa is in pilot and trained on synthetic data; DoorDash's MCP is in limited beta; the application layer persists for compliance-heavy workflows; individual AI usage patterns are idiosyncratic and must be shared to avoid vendor lock-in.
