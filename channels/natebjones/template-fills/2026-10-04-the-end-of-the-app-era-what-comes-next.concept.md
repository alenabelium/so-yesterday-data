## TL;DR

Software is splitting into three layers — data, application, and agent — and every company, from Meta to DoorDash, is repositioning around them. Buyers and builders must learn to talk in these terms or risk losing value.

## The argument

### Define the three-layer stack
- **Anchor Timestamps**: ['00:23:58']
- **Claim**: Every software offering now decomposes into three layers: the data layer (who provides structured, agent-readable information), the application layer (the interface and workflows), and the agent layer (the AI that acts on your behalf).
- **Role**: definition

### Data layer as the new moat
- **Anchor Timestamps**: ['00:07:43']
- **Claim**: Meta's Muse for Small Business connects to business accounts, Shopify, and QuickBooks — not to sell software but to own the data layer. In the agent era, whoever controls the data the agent needs becomes indispensable.
- **Role**: evidence

### Application layer decomposes into workflows
- **Anchor Timestamps**: ['00:27:17']
- **Claim**: The application layer isn't dead — it splits into interfaces and workflows. Workday's payroll agent relies on compliance-heavy workflows that remain valuable even if the interface changes, because no startup wants to hand-code payroll rules.
- **Role**: evidence

### Agent layer as the new battleground
- **Anchor Timestamps**: ['00:15:31']
- **Claim**: Labs like OpenAI and Anthropic lack your data and distribution, so they bet on intelligence. Salesforce counters with Koa plus a control panel that lets buyers choose any model — turning the agent layer into a flexible, multi-tenant gateway.
- **Role**: synthesis

### Counter: agent access is table stakes
- **Anchor Timestamps**: ['00:19:24']
- **Claim**: Simply offering an MCP server or an agent interface doesn't justify continued payment. If two providers offer equal data and execution, the agent makes them easy to compare and replace — so you must also deliver unique workflow value.
- **Role**: counter

## Evidence and caveats

DoorDash's text ordering and MCP beta show that losing the interface doesn't mean losing the transaction — but Nate admits this is a minimum requirement, not a differentiator. Salesforce's Koa is in pilot and trained on synthetic data, not real customer data. The recruiting story is anonymized, and Nate hedges that not every CFO will review individual AI usage. Workday's payroll agent is described as using 'customized data and company rules' — a claim from the vendor, not independently verified.
