## Thesis

Microsoft's Autopilot, built on OpenClaw, will reach far more workers than any other AI this year, and the value it delivers depends on data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft has 450 million paid Microsoft 365 seats, versus OpenAI's 9 million business users. Autopilot is embedded in Excel, Outlook, and Teams, so it appears wherever you already work. The agent is not smarter—it's just everywhere. The value comes from the data it can access and how well you use it. This creates a K-shaped future: people with the same tools get wildly different results. The first practice is to define what 'good' looks like. Tell the AI the outcome you want, not just the task. For a contract renewal, ask it to identify outstanding obligations and what needs to happen before the conversation. Then check if the data it synthesized helps you act. The second practice is to put the right information in front of the model and verify it used it. Give it the account plan, commitments, and service records. Tell it which source takes priority. Ask for evidence links. If the response is weak, check what data it had before blaming the model. The third practice is to make good tasks repeatable. Once a briefing works, set a trigger and a schedule. Autopilot has identity, memory, and a workspace, so it can run continuously. Use Copilot's scheduled prompts if you don't have Autopilot yet. The fourth practice is to match reasoning to complexity. Routers pick models based on cost and speed, but they can't tell the difference between 'What is this?' for a syntax error versus a complex coding problem. ## Counterpoints

- A sufficiently powerful model can redesign workflows, eliminating steps that exist only to coordinate human activity, which is Anthropic's strongest argument for enterprise adoption.
- Microsoft doesn't have its own frontier model, so it may lose the intelligence race even if it wins distribution.
- Autopilot is not very smart; it's the data access and user skill that create value, not the model's intelligence.
- Routers can waste tokens figuring out task complexity, sometimes costing more than just using a smart model.
- Meta's enterprise platform and personal agents could challenge Microsoft by leveraging its customer relationships and data.
