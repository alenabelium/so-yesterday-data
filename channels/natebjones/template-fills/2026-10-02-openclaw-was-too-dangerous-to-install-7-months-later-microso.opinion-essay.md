## Thesis

Microsoft's Autopilot, built on OpenClaw, will reach far more workers than any rival AI this year, and the value it delivers depends on user skill and data access, not model intelligence.

## Argument

The mechanism is distribution. Microsoft already covers 450 million paid Microsoft 365 seats, while OpenAI has only 9 million paid business users. Autopilot is embedded in Excel, Outlook, and Teams, so it appears wherever you already work. The model itself isn't smart—the value comes from the data it can access and how well you use it. This creates a K-shaped future: people with the same tools get very different results.

Five practices determine which slope you land on. First, define what 'good' looks like. Give Autopilot a specific task and tell it what a useful outcome is. Second, put the right information in front of the model and verify it actually used it. Provide account plans, commitments, and service data, and ask for an evidence tree. Third, make good tasks repeatable. Set up scheduled prompts or agents that run on a trigger, and monitor their output for real changes. Fourth, match reasoning to complexity. Use stronger models for hard problems, and give the router context like purpose and past failures. Fifth, obsess over improving the next run. Fix the cause of failures, save what works, and share it with colleagues.

Microsoft's advantage is trust and distribution. It can sell Autopilot to existing customers without a new vendor asking for access to company data. But the strongest counterargument is that better models, like Anthropic's, can redesign workflows entirely, making Microsoft's processes obsolete. The real competition is about who understands the job well enough that we keep coming back to delegate work.

## Counterpoints

- Microsoft doesn't have its own frontier model, so labs like Anthropic could redesign workflows more efficiently.
- Autopilot's router may waste tokens deciding which model to use, making it cheaper to just use a smart model.
- A cheap model might miss implicit commitments, producing a readable briefing that misses the point.
- Repeating a weak assignment just gives you more weak reading scores.
