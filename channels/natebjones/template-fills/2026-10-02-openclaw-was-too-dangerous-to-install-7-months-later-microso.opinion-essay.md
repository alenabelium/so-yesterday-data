## Thesis

Microsoft is bringing OpenClaw-derived agents to 450 million workers via Autopilot, and the value will come from data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft's 450 million paid Microsoft 365 seats dwarf OpenAI's 9 million business users, and Autopilot is embedded in tools people already use. The value isn't in the model's intelligence—it's in the data it can access and how well you use it. This creates a K-shaped future where some get vastly more value from the same tools. To be on the upward slope, you need five practices: define what 'good' looks like, provide the right context and data, make tasks repeatable, match reasoning to complexity, and obsessively improve the next run. Microsoft's advantage is trust and existing relationships, but it lacks its own frontier model, leaving room for competitors like Anthropic to redesign workflows. The real competition is about who understands the job well enough to keep you coming back.

## Counterpoints

- Microsoft's model isn't the smartest, but value comes from data access and user skill, not intelligence.
- A sufficiently powerful model could redesign workflows, making current processes obsolete—Anthropic's argument.
- Routing to cheaper models may save tokens but can fail on complex tasks, costing more in rework.
- Meta's enterprise platform and data could challenge Microsoft's workplace dominance.
