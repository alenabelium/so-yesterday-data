## Thesis

Microsoft's Autopilot, built on OpenClaw-derived technology, will reach far more workers than any other AI this year, and its value depends on data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft has 450 million paid Microsoft 365 seats, dwarfing OpenAI's 9 million business users. Autopilot is embedded in Excel, Outlook, and Teams, so it appears wherever you already work. The value isn't in the model's intelligence—it's in the data it can access and how well you use it. This creates a K-shaped future: people with the same tools get vastly different results.

To land on the upward slope, you need five practices. First, define what 'good' looks like for a real task, like a contract renewal. Second, give the model the right context and data, and check that it actually used the evidence. Third, make successful tasks repeatable—set triggers, schedules, and limits. Fourth, match reasoning to complexity: separate routine prep from nuanced interpretation, and be aware of router limitations. Fifth, obsessively improve the next run—fix the cause of failures, save what works, and share it.

Microsoft's advantage is trust and existing relationships. IT departments already manage Microsoft, so deploying Autopilot is easier than onboarding a new vendor. The company can monetize by calling existing customers, and it doesn't need to win every model comparison. But the strongest counterargument is that better models, like Anthropic's, could redesign workflows entirely, making Microsoft's processes obsolete. Still, for most workers, the AI you're allowed to use is Microsoft's, and that's where the learning happens.

## Counterpoints

- Microsoft's model isn't the smartest, but value comes from data access and user skill, not intelligence.
- A sufficiently powerful model could redesign workflows, making Microsoft's processes obsolete.
- Router systems may not have enough context to distinguish simple from complex tasks, leading to misrouting.
- Meta's enterprise platform could challenge Microsoft by leveraging its customer relationships and data.
