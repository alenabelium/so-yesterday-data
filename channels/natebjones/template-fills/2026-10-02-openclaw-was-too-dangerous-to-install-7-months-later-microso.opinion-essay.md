## Thesis

Microsoft is bringing OpenClaw-derived agent technology to the enterprise as Autopilot, and the real value will come not from model intelligence but from data access and user skill, creating a K-shaped future.

## Argument

The mechanism is distribution. Microsoft already covers 450 million paid Microsoft 365 commercial seats, compared to OpenAI's 9 million paid business users. Employers pay for these accounts, and IT departments administer them, so Microsoft is the AI that most people are allowed to use at work. Autopilot, based on the open-source OpenClaw technology, embeds agentic workflows into the apps companies already use, making delegation accessible without needing to be an engineer. The value isn't in intelligence—Autopilot isn't very smart—but in the data it can access and how well you use it. The first practice is to define what 'good' looks like: give the AI a specific task tied to a real responsibility, and tell it what a useful result would be. The second is to put the correct information in front of the model and check if it actually used it—provide current account plans, commitments, and service data, and ask for an evidence tree. The third is to make successful tasks repeatable: set triggers, define accountability, and test the next run. The fourth is to match reasoning to complexity, especially with automatic routing—a cheap model can handle routine prep, but you need to consciously use stronger reasoning for the hard parts. The fifth is to obsessively improve the next launch: fix the cause of failures, save what works, and share it with colleagues. This is a skill problem, not an intelligence problem, and it will determine which side of the K-shape you end up on.

## Counterpoints

- The strongest argument against assuming Microsoft is winning is that labs like Anthropic are serious about improving the model itself—a sufficiently powerful model could redesign workflows entirely, making many human-coordination steps unnecessary.
- A common failure mode is repeating a weak assignment, which just gives you more weak reading scores—you need to check if the agent actually noticed what changed or just rehashed what you already knew.
- Routing is hard: a router sees only the words 'What is this?' and can't distinguish between a trivial syntax error and a complex coding problem, so it may choose a cheaper model that fails on the hard task.
- Meta is a contender with huge data and distribution, targeting small businesses with tools that combine Facebook and Instagram business info, ad campaigns, and Google Workspace—competing for customer relationships, not just model benchmarks.
