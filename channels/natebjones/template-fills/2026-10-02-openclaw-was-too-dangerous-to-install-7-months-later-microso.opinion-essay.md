## Thesis

Microsoft's Autopilot, built on OpenClaw, will reach more workers than any rival AI this year, and the value it delivers depends on data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft already covers 450 million paid Microsoft 365 seats, versus OpenAI's 9 million business users, and it's embedding Autopilot into Excel, Outlook, and Teams. That's why this launch matters more than anything from OpenAI or Anthropic this year. The agent isn't smart—I'm not going to pretend it is—but it has access to your company's data, and that's where the value comes from. The future is K-shaped: people with the same tools get wildly different results. To land on the upper slope, you need five practices. First, define what "good" looks like for a real task, like a contract renewal briefing. Tell the AI what a useful summary includes, and show it an example. Second, give it the right context and data. If it misses a commitment, check whether it had access to the source—often the problem is permissions, not intelligence. Third, make good tasks repeatable. Set up scheduled prompts or agents that run on a trigger, and monitor whether they actually notice changes. Fourth, match reasoning to complexity. Routers that pick models based on cost can misfire when the same words mean different things—like "What is this?" for a syntax error versus a three-hour coding problem. You need to provide context that helps the router decide. Fifth, obsess over improving the next run. When something fails, find out why—missing data, unclear instructions, or model limits—and fix it. Share what works. This is a skill that travels with you, regardless of which vendor your company picks.

## Counterpoints

- A sufficiently powerful model could redesign workflows entirely, eliminating the need for reports and meetings that exist only to coordinate humans—this is Anthropic's strongest argument for enterprise adoption.
- Microsoft doesn't have its own frontier model, so it may lose the intelligence race even if it wins distribution.
- Autopilot's router may spend more tokens figuring out which model to use than just sending the task to a smart model.
