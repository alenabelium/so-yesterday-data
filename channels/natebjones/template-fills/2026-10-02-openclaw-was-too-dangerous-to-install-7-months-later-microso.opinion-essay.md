## Thesis

Microsoft is bringing OpenClaw-derived agents to 450 million seats, and the value will come from data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft already manages the workplace for roughly half a billion people, while OpenAI has only 9 million paid business users. An agent your employer approves of matters more to your workday than the model everyone argues about online. Autopilot isn't very smart, but that's not the point. The value comes from the data it can access and how well you use it.

First, define what 'good' looks like. Give Autopilot a specific task, like identifying outstanding customer obligations before a renewal conversation. Then check if the data it synthesizes actually helps you act. Most people leave the standard unspoken, so they get average results.

Second, put the correct information in front of the model and verify it used it. Provide the account plan, client commitments, and service records. Tell it which source takes priority. Ask for an evidence tree and open the links. If the response is weak, check what information the tool had before blaming the model.

Third, make good tasks repeatable. Once you get a result you'd actually use, decide what triggers the agent to start again and what it's responsible for between runs. Autopilot has an identity, memory, computer, and workspace. Set a schedule, set limits, and test the next run.

Fourth, match reasoning to complexity. Separate routine preparation from consistent interpretation. A cheap model can handle obvious syntax errors, but not a three-hour coding problem. If you can't choose the model, break the task into steps and identify where it consistently fails.

Fifth, obsessively improve the next use.
