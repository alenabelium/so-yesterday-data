## Thesis

Microsoft's Autopilot, built on OpenClaw, will reach far more workers than any other AI this year, and its value depends on data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft's 450 million paid Microsoft 365 seats dwarf OpenAI's 9 million business users, and Autopilot is embedded in the tools people already use—Excel, Outlook, Teams. This isn't about being smarter; it's about being everywhere, with credentials IT can verify and a support contract. The real value comes from the data it can access and how well you use it. The future is K-shaped: people with the same tools get wildly different results. To land on the upward slope, you must master five practices. First, define what 'good' looks like—give the agent a specific task and tell it what a useful outcome is. Second, put the right information in front of the model and check if it used it; give it the account plan, the commitments, the service history, and tell it which sources take priority. Third, make good tasks repeatable—set up scheduled prompts or agents that run on a trigger, and test each run to see if it actually noticed what changed. Fourth, match reasoning to complexity—separate routine preparation from consistent interpretation, and give hard problems the context and model they need. Fifth, obsessively improve the next launch—when something fails, find out why, fix the cause, and share what works. Microsoft's advantage is data access, not intelligence, and that's why this launch deserves attention even if you've never used a terminal.

## Counterpoints

- A sufficiently powerful model can find more efficient ways to do corporate work, potentially eliminating the need for reports and meetings that exist only to coordinate human activity.
- Anthropic's guided agents and Claude's Excel/Word add-ins could make another company the place we start when we want the job done, even if Microsoft keeps the documents.
- Meta's Enterprise Platform and Muse target small businesses with customer data and ad campaigns, creating a new competitor for business AI relationships.
- Automatic routing can waste tokens figuring out which model to use, and a cheap model may fail on complex tasks, costing more in rework than a smarter model would.
