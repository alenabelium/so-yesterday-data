## Thesis

Microsoft's Autopilot, built on OpenClaw, will reach far more workers than any other AI this year, and the value it delivers depends on data access and user skill, not model intelligence.

## Argument

The mechanism is distribution. Microsoft already has 450 million paid Microsoft 365 seats, and Autopilot is embedded in the tools people already use—Excel, Outlook, Teams. That's why it will reach more working people than anything OpenAI or Anthropic releases this year. Not because it's better, but because it's everywhere. The value comes from the data it can access and how well you know how to use AI. Autopilot itself isn't very smart—I'm not going to pretend that's the case. The point is that value is not in intelligence. It's in the data and the skill of the user. This creates a K-shaped future: people with the same tools get very different results. To land on the upward slope, you need five practices. First, define what 'good' looks like. Give Autopilot a specific task and tell it what a useful outcome is. Second, put the correct information in front of the model and check if it actually used it. Give it the account plan, the commitments, the service records. Tell it which source takes priority. Third, make a good task repeatable. Set a schedule, define the trigger, and specify what the agent is responsible for between runs. Fourth, match reasoning to complexity. Separate routine preparation from consistent interpretation. Use a stronger model for the hard parts. Fifth, obsessively improve the next run. When something fails, find out why—was it missing data, unclear instructions, or a model that didn't understand? Save the fixes and share what works. This is the skill that will travel with you, no matter which AI your employer adopts.

## Counterpoints

- A sufficiently powerful model can find a more efficient way to prepare updates, potentially eliminating the need for weekly reports and meetings, which is the strongest argument for Anthropic's enterprise scaling.
- Microsoft doesn't have its own frontier model, so it may lose the intelligence race to labs like Anthropic, even if it wins on distribution.
- Router systems may spend more tokens figuring out which model to use than just sending the task to a smart model, especially for complex new problems.
- Meta is entering the enterprise space with its own platform, targeting small businesses with data from Facebook and Instagram, creating a new competitive front.
