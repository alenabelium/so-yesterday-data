## Headline takeaway

Turn repetitive browser work into scheduled, autonomous tasks with the Claude Chrome extension.

## Prerequisites

### Paid Claude plan
- **Kind**: account
- **Note**: The extension is available to anyone on a paid plan; higher tiers unlock smarter models for complex tasks.

### Chrome browser
- **Kind**: tool
- **Note**: The extension runs inside Chrome, which comes with most computers and supports tab groups.

## Steps

### Install the Claude extension and open the sidebar
- **Timestamp**: [00:00](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=0)
- **Action**: Add the Claude extension to Chrome and open its sidebar. This gives you a chat window that can operate the active page, type into fields, click buttons, and navigate.
- **Command Or Clicks**: Install from Chrome Web Store, then click the extension icon to open the sidebar.

### Record a repetitive workflow as a shortcut
- **Timestamp**: [04:00](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=240)
- **Action**: Click the record icon in the extension panel, perform the task you want to automate (e.g., pulling analytics, checking pricing, extracting CRM data), then stop recording and save it as a shortcut.
- **Command Or Clicks**: Click the record icon, perform the task, click stop, then save as a shortcut.

### Schedule the shortcut to run on autopilot
- **Timestamp**: [04:45](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=285)
- **Action**: Use the clock icon to set a daily, weekly, monthly, or annual cadence. Claude runs the task automatically as long as the computer is on and the browser is active.
- **Command Or Clicks**: Click the clock icon, choose cadence, and save.

### Use Claude's built-in knowledge for Gmail, Calendar, and Drive
- **Timestamp**: [07:30](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=450)
- **Action**: Open Gmail, Google Calendar, or Google Drive and let Claude scan, organize, and draft. Claude has built-in knowledge of these platforms, so no step-by-step instructions are needed.
- **Command Or Clicks**: Open Gmail, Calendar, or Drive; use the sidebar to ask Claude to scan, organize, or draft.

### Work across multiple tabs with tab groups
- **Timestamp**: [09:42](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=582)
- **Action**: Group related tabs in Chrome and designate them for Claude. Claude can read and interact with all tabs in the group simultaneously, synthesizing content into structured output.
- **Command Or Clicks**: Drag tabs into a Chrome tab group; Claude sees only those tabs.

### Generate Excel files with co-work
- **Timestamp**: [10:26](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=626)
- **Action**: In co-work, ask Claude to work with a group of tabs, extract data, and produce an Excel file with a specified format. This turns multi-tab data extraction into a deliverable document.
- **Command Or Clicks**: In co-work, say: 'Work with this group of tabs' and 'make it into an Excel file with this format'.

### Set up scheduled website testing
- **Timestamp**: [12:53](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=773)
- **Action**: Record a test flow (e.g., a checkout) and schedule it to run regularly. Claude will execute the flow and report if the site is still working, serving as a simple smoke test.
- **Command Or Clicks**: Record the flow, then schedule it (e.g., 'every morning at 9:00').

## Gotchas

### Avoid automated email replies; risk of sending wrong message to wrong person or hitting send instead of draft. Use for cleanup, not sending.
- **Severity**: serious
- **Timestamp**: [08:15](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=495)

### Data-heavy tasks (e.g., scanning many LinkedIn contacts) can be spotty; Claude may miss posts or focus on tangential updates. Break into subtasks.
- **Severity**: heads_up
- **Timestamp**: [15:58](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=958)

### Prompt injection risk on untrusted sites; malicious text can hijack the agent. Use only on trusted sites and review sensitive actions.
- **Severity**: blocking
- **Timestamp**: [19:30](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=1170)

### Don't open bank accounts or grant infinite permissions; treat Claude like a capable but new employee and verify output.
- **Severity**: serious
- **Timestamp**: [20:18](https://www.youtube.com/watch?v=QT7W_uHjqWE&t=1218)
