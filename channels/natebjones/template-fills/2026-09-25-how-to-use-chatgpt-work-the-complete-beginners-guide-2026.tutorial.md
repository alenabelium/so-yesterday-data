## Headline takeaway

Master ChatGPT Work and Codex for cloud/local tasks, document editing, spreadsheet cleaning, image data extraction, research verification, browser automation, project management, and token cost control.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Required for ChatGPT Work and Codex access; verify plan includes Astra model.

### Desktop Application
- **Kind**: tool
- **Note**: Install latest version to enable local mode, project folders, and computer history features.

### MacOS (Optional)
- **Kind**: os
- **Note**: Computer history feature is macOS-specific for Pro/Business/Enterprise accounts.

## Steps

### Select Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Choose cloud tasks for background execution when the laptop is closed, or local tasks for accessing specific computer files and applications. Ensure the computer stays awake for local work.
- **Command Or Clicks**: In desktop app, find 'local control work' element to switch modes.
- **Choice Branch**: Cloud: Leave laptop closed. Local: Keep computer on and prevent sleep mode.

### Enable Voice Interaction
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use dictation for quick text input or voice chat for live conversation with tool access. On supported Macs, enable screen context to let the AI see your window.
- **Command Or Clicks**: Select 'start voice chat' or use external tools like Whisper.
- **Choice Branch**: Voice chat allows live feedback; dictation is faster for text entry.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Instruct AI to make specific changes (e.g., 'save headers, change explanation') rather than general rewrites. Always review the actual file for formatting and table overflow.
- **Command Or Clicks**: Ask AI to edit connected Google Docs or Word files directly.
- **Choice Branch**: Beginners: Ask for a copy first. Experts: Edit working file after verification.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Define duplication rules before cleaning. Ask for a cleaned copy with an explanation of deleted rows. Verify formulas remain formulas and dates are formatted correctly.
- **Command Or Clicks**: Ask AI to 'clean the file' and 'provide a cleaned copy'.
- **Choice Branch**: Standardize names before deleting duplicates to avoid merging distinct entries.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) and specify exact fields to extract. Instruct AI to leave cells blank if data is missing rather than guessing zero.
- **Command Or Clicks**: Upload 30+ photos and request a table with specific columns.
- **Choice Branch**: Specify 'leave blank if not visible' to distinguish from zero values.

### Verify Research Sources
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and show source divergence. Check publication dates to avoid outdated information. Request a compact evidence table before final reports.
- **Command Or Clicks**: Prompt: 'Show me divergence' and 'Provide source, date, uncertainty'.
- **Choice Branch**: Treat hypotheses as unconfirmed until verified by real customers.

### Use Browser for Live Data
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Let AI search and compare live website data. Provide specific restrictions (dates, location) to narrow results. Ask for direct links to verify details.
- **Command Or Clicks**: Use browser integration to search flights or prices.
- **Choice Branch**: Cloud browser has its own session; do not assume local login carries over.

### Connect Apps via Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins for services like Slack or Google Calendar. Authenticate accounts and start a new task to activate connections. Specify calendar details precisely.
- **Command Or Clicks**: Open plugins, install service, connect account, start new task.
- **Choice Branch**: Verify if the plugin can read/write; some only allow reading.

### Manage Projects and Skills
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to store common sources and instructions. Create skills (markdown files) for reusable workflows. Reduce instruction length by removing redundant advice.
- **Command Or Clicks**: Edit project to add folders; create agents.markdown for skill instructions.
- **Choice Branch**: Local projects can connect to multiple folders; set one as primary.

### Configure Computer History
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)
- **Action**: Enable computer history in settings for macOS Pro/Business accounts. Review included programs/websites before activation. Disable if working with confidential info without consent.
- **Command Or Clicks**: Settings > Computer History > Turn On.
- **Choice Branch**: History uses interaction events; it does not record screen/audio.

### Select Models and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Choose models based on task complexity (Astra for complex, Terra for simple). Adjust reasoning effort only when necessary. Compare results to ensure cost-effectiveness.
- **Command Or Clicks**: Select model and effort level in the hint field.
- **Choice Branch**: Don't use max/ultra settings for simple reformatting tasks.

### Use Parallel Agents
- **Timestamp**: [43:16](https://www.youtube.com/watch?v=Risal7sjYms&t=2596)
- **Action**: Delegate independent subtasks to multiple agents (e.g., searching different retailers). Ensure the main agent reconciles results and provides a unified recommendation.
- **Command Or Clicks**: Ask AI to 'Divide independent research' and 'provide one unified response'.
- **Choice Branch**: Avoid parallel agents if they need to edit the same file simultaneously.

### Create Interactive Websites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material into a lightweight website or app. Specify visitor needs and interactive elements (filters, notes) to make it useful.
- **Command Or Clicks**: Ask AI to 'convert assignment material to a lightweight website'.
- **Choice Branch**: Check preview before private deployment; verify mobile compatibility.

### Set Goals and Plans
- **Timestamp**: [48:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2893)
- **Action**: Use /goal for long tasks with clear stopping conditions. Use /plan to determine solutions before acting. Manage progress via side chat while the main task runs.
- **Command Or Clicks**: Type '/goal' or '/plan' in the input field.
- **Choice Branch**: Goals require measurable outcomes; plans help define the approach.

### Schedule Recurring Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Ask AI to schedule a task with specific frequency and time zone. Check the saved schedule to confirm instructions and timing. Use separate launches for independent reports.
- **Command Or Clicks**: Ask 'Schedule this weekly briefing at 8:00 AM Pacific Time'.
- **Choice Branch**: Cloud schedules run regardless of laptop; local schedules need the computer on.

### Set Up Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Create monitors for Gmail, Slack, or GitHub that trigger actions only when specific conditions are met. Instruct the agent to save missing info and recognize processed items.
- **Command Or Clicks**: Ask AI to 'Search message with this topic' and 'let me know only when needed'.
- **Choice Branch**: Event triggers cannot be combined with time-based schedules.

### Share Work and Snapshots
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files or sites directly. For Codex, share a read-only snapshot of the desktop. Ensure permissions are correct before sharing.
- **Command Or Clicks**: Open sharing in Codex and select access settings.
- **Choice Branch**: Snapshots do not update with new changes; share new results separately.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Check token consumption for large tasks. Use Astra's limit commands to control spending. Verify API key billing if using external access.
- **Command Or Clicks**: Prompt: 'Use my limit as long as it will not reach 25%'.
- **Choice Branch**: Voice operations and background functions also consume tokens.

### Fix Stuck or Bad Results
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: Ask the AI for status if stuck. Point out specific errors rather than saying 'bad result'. Stop current implementation if necessary, then restore from version control.
- **Command Or Clicks**: Ask 'What is happening?' or 'Stop current implementation'.
- **Choice Branch**: Check external actions (files/messages) before retrying.

## Gotchas

### Local tasks stop if the computer sleeps. Prevent sleep mode during long local work.
- **Severity**: blocking
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)

### Cloud tasks cannot access local files directly. Add materials to a connected location first.
- **Severity**: serious
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Do not enter credentials in conversation. Use supported step transmission for logins.
- **Severity**: blocking
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer history includes accessible text which may contain confidential info. Disable if working with sensitive data without consent.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that override your request (prompt injection). Be careful with content sources.
- **Severity**: serious
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)
