## Headline takeaway

Master ChatGPT Work and Codex for cloud/local tasks, surgical editing, spreadsheet cleaning, image extraction, research, browser automation, scheduling, and token management.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Required for Astra model access in Work/Codex. Verify plan includes Astra.

### macOS Desktop App
- **Kind**: os
- **Note**: Needed for local mode, computer history, and project folder integration.

### Browser Access
- **Kind**: tool
- **Note**: Required for browser-based tasks and plugin authentication workflows.

## Steps

### Choose Cloud vs Local Mode
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Select cloud mode to leave tasks running while the laptop is closed, or local mode for file access and background scheduling. Ensure the computer stays awake for local tasks.
- **Command Or Clicks**: In desktop app, find 'local control work' toggle. Prevent sleep mode for local tasks.
- **Choice Branch**: Cloud: Leave and return later. Local: Keep computer on and app open.

### Use Voice Chat for Context
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Start voice chat to provide natural context or coordinate tasks. Use dictation for quick hints. On Mac, enable screen context to let AI see the active window.
- **Command Or Clicks**: Select 'start voice chat'. Configure hotkeys in settings.
- **Choice Branch**: Voice chat allows live conversation; dictation is for quick text input.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Ask AI to edit specific parts of existing documents (Google Docs/Word) without rewriting. Specify what to save and what to change. Check for table overflow.
- **Command Or Clicks**: Request: 'Save headers, change explanation in this section.'
- **Choice Branch**: Beginners: Ask for a copy first. Experts: Edit working file directly.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Define duplication rules before cleaning. Ask for a cleaned copy with an explanation of deleted rows. Verify date formatting and currency values.
- **Command Or Clicks**: Ask: 'Show me duplicates before standardizing names.'
- **Choice Branch**: Ensure formulas remain formulas if the sheet needs future editing.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) and specify exact fields to extract. Instruct AI to leave cells blank if data is missing, rather than guessing zero.
- **Command Or Clicks**: Request: 'Seller column, date, total amount, category.'
- **Choice Branch**: Specify limits for ambiguous cases to prevent hallucination.

### Conduct Rigorous Research
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and show source divergence. Verify publication dates and evidence. Request a compact table of evidence before final reports.
- **Command Or Clicks**: Prompt: 'Show me divergence in sources.'
- **Choice Branch**: Mark hypotheses clearly; do not treat initial findings as facts.

### Use Browser for Live Data
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Use the browser tool to search and compare live data (e.g., flights). Provide specific restrictions like dates and currency. Ask for direct links to verify.
- **Command Or Clicks**: Ask AI to 'search and compare' with specific constraints.
- **Choice Branch**: Cloud browser has its own session; do not assume local login sync.

### Connect Apps via Plugins
- **Timestamp**: [27:20](https://www.youtube.com/watch?v=Risal7sjYms&t=1640)
- **Action**: Install plugins for apps like Slack or Google Docs. Authenticate accounts and start a new task to ensure access. Be specific about which calendar/account to use.
- **Command Or Clicks**: Open plugins menu, install service, authenticate account.
- **Choice Branch**: Check if the plugin supports read/write actions before relying on it.

### Manage Projects and Skills
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to store sources and instructions. Create skills (markdown files) for reusable workflows. Clean up old instructions to reduce token usage.
- **Command Or Clicks**: Edit project, add folders, create agents.markdown file.
- **Choice Branch**: Local projects connect to computer folders; cloud projects use library.

### Enable Computer History
- **Timestamp**: [33:59](https://www.youtube.com/watch?v=Risal7sjYms&t=2039)
- **Action**: Turn on computer history in macOS settings for Pro/Business accounts. Review included programs/websites. Disable if sharing devices without consent.
- **Command Or Clicks**: Settings > Computer History > Turn On.
- **Choice Branch**: History uses interaction events, not screen/audio recording.

### Select Models and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Choose models based on task complexity (Astra for complex, Luna for simple). Adjust reflection effort. Use parallel agents for independent subtasks.
- **Command Or Clicks**: Select model/effort in hint field. Ask for parallel agents.
- **Choice Branch**: Stronger settings don't fix wrong source data.

### Create Interactive Websites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material into a lightweight website with filters. Specify visitor needs and interactive elements. Check preview before private deployment.
- **Command Or Clicks**: Ask AI to 'convert to website' with specific filter requirements.
- **Choice Branch**: Static sites are less useful than interactive ones for investigation.

### Use Goals and Planning
- **Timestamp**: [48:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2893)
- **Action**: Use goals for long tasks with clear stopping conditions. Use planning to propose solutions before acting. Manage progress via side chat.
- **Command Or Clicks**: Type {slash} goal or {slash} plan in supported interfaces.
- **Choice Branch**: Goals require measurable outcomes; plans propose approaches.

### Schedule Recurring Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Schedule tasks with precise time zones and sources. Check the schedule to confirm it exists. Use separate launches for independent reports.
- **Command Or Clicks**: Ask AI to 'schedule this weekly briefing at 8 AM Pacific.'
- **Choice Branch**: Cloud schedules run independently; local schedules need computer on.

### Set Up Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Use event triggers (Gmail/Slack) to monitor for specific conditions. Instruct AI to save missing info and only notify when action is needed.
- **Command Or Clicks**: Prompt: 'Search message with topic X, let me know only if Y.'
- **Choice Branch**: Triggers cannot combine time schedules with event triggers.

### Share Work and Snapshots
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files or sites directly. For Codex, share a read-only snapshot. Explain permissions clearly to avoid security risks.
- **Command Or Clicks**: Open sharing menu in Codex, select access settings.
- **Choice Branch**: Snapshots are static; they do not update with new changes.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Check token consumption for large tasks. Use Astra's limit commands to stay within budget. Verify API key billing if applicable.
- **Command Or Clicks**: Prompt: 'Use my limit as long as it does not reach 25%.'
- **Choice Branch**: Voice operations and background functions also consume tokens.

### Fix Stuck or Bad Results
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: Ask for status if stuck. Be specific about errors. Stop current implementation if needed. Use version control to restore previous states.
- **Command Or Clicks**: Prompt: 'What is happening? What completed?'
- **Choice Branch**: Do not repeat external actions until their status is verified.

## Gotchas

### Local tasks stop if the computer sleeps. Prevent sleep mode for long local work.
- **Severity**: blocking
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)

### Cloud tasks cannot access local files. Upload materials to a connected location first.
- **Severity**: serious
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Do not enter credentials in chat. Use supported step transmission for logins.
- **Severity**: blocking
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer history includes accessible text, which may contain confidential info. Disable if sharing devices.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that override your request (prompt injection). Be careful with sources.
- **Severity**: blocking
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)
