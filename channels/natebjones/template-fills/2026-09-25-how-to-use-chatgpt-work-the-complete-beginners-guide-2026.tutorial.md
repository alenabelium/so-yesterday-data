## Headline takeaway

Master ChatGPT Work and Codex for cloud tasks, surgical edits, spreadsheet cleaning, image data extraction, research verification, browser automation, project context, and token-safe scheduling.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Pro, Business, or Enterprise tier required for Astra model access and computer history features.

### Desktop Application
- **Kind**: tool
- **Note**: Installed ChatGPT desktop app to enable local execution modes and project folder connections.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Decide between cloud and local execution based on whether you need to leave the task running while offline or require access to local files.
- **Command Or Clicks**: In desktop app, find 'local control work' element. Select cloud for background/offline tasks; select local for folder access.
- **Choice Branch**: If leaving laptop, use cloud. If needing local files, use local and prevent sleep mode.

### Enable Voice Interaction
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use voice dictation for context or live voice chat for flexible conversation without typing.
- **Command Or Clicks**: Select 'start voice chat' in supported tasks. Use external tools like Whisper if needed.
- **Choice Branch**: Use dictation for fast hints; use live voice chat for complex, evolving instructions.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Instruct AI to make specific changes to existing documents without rewriting the entire file.
- **Command Or Clicks**: Say: 'Save headers, save link, change explanation in this section.' Request a copy first for safety.
- **Choice Branch**: Beginners should request a copy with notes. Experts can edit directly after verifying changes.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Standardize names and remove duplicates before cleaning a workbook to avoid data loss.
- **Command Or Clicks**: Ask for a cleaned copy with an explanation of deletions. Specify filters, frozen headings, and currency formatting.
- **Choice Branch**: Ensure formulas remain formulas if editing is required later. Verify date sorting.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Convert photos (e.g., receipts) into structured table rows with source tracking.
- **Command Or Clicks**: Specify fields: 'Seller, Date, Total, Currency, Category'. Instruct to leave blank if tax info is missing.
- **Choice Branch**: Distinguish between empty values and zeros for financial accuracy. Check for duplicate image processing.

### Verify Research Sources
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and verify sources, publication dates, and definitions.
- **Command Or Clicks**: Request a compact table of evidence: source, date, uncertainty. Ask for divergence if sources conflict.
- **Choice Branch**: Mark hypotheses clearly. Do not treat long source lists as conviction without verification.

### Use Browser Integration
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Allow AI to browse websites for real-time data, using local or cloud browser sessions.
- **Command Or Clicks**: Enable browser tools in settings. Provide login credentials via supported step transmission if needed.
- **Choice Branch**: Never enter passwords in chat. Use specific browser restrictions (dates, travelers) for accurate results.

### Connect Apps and Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins to allow AI to interact with services like Google Calendar or Slack.
- **Command Or Clicks**: Open plugins, find service, install, and connect account. Start a new task after installation.
- **Choice Branch**: Be specific about accounts (e.g., which calendar). Check for existing records before creating events.

### Manage Project Context
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to store sources, instructions, and files for recurring tasks.
- **Command Or Clicks**: Select 'Edit project' in desktop app. Add folders as sources. Name files clearly.
- **Choice Branch**: Local projects can connect to computer folders. Avoid overloading context windows with too many folders.

### Configure Computer History
- **Timestamp**: [33:59](https://www.youtube.com/watch?v=Risal7sjYms&t=2039)
- **Action**: Enable macOS computer history for Pro/Business/Enterprise users to restore past work.
- **Command Or Clicks**: Go to Settings > Computer History. Turn on memory activation. Review included programs/websites.
- **Choice Branch**: Disable if working with confidential info without consent. Use 'only include' mode for privacy.

### Select Model and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Choose models (Astra, Soul, Terra, Luna) and reasoning effort based on task complexity.
- **Command Or Clicks**: Look under hint field for model selection. Use Astra for demanding work; Luna for cost-effective repetitive tasks.
- **Choice Branch**: Do not use complex settings for simple reformatting. Increase effort only for controversial evidence or complex plans.

### Use Parallel Agents
- **Timestamp**: [43:16](https://www.youtube.com/watch?v=Risal7sjYms&t=2596)
- **Action**: Delegate independent parts of a task to multiple agents for parallel processing.
- **Command Or Clicks**: Ask main agent to divide research. Specify criteria and unified response format.
- **Choice Branch**: Avoid parallel agents if they need to edit the same file. Use for independent searches or comparisons.

### Create Interactive Websites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material into a lightweight website or application for interactive viewing.
- **Command Or Clicks**: Ask AI to convert material to a site. Specify filter options and user goals.
- **Choice Branch**: Check preview before private deployment. Distinguish between working preview and published site.

### Set Goals and Plans
- **Timestamp**: [49:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2953)
- **Action**: Use Goals for long tasks with clear stopping conditions, and Plans for complex problem-solving.
- **Command Or Clicks**: Type '/goal' or '/plan' in supported desktop interfaces. Describe result or approach.
- **Choice Branch**: Goals require measurable outcomes. Use side chat for status questions while the main task runs.

### Schedule Recurring Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Automate repetitive tasks by scheduling them to run at specific times or frequencies.
- **Command Or Clicks**: Ask task to schedule repetition. Specify time zone (e.g., '8:00 a.m. Pacific Time').
- **Choice Branch**: Check saved schedule for next launch time and instructions. Use separate launches for new reports.

### Configure Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Set up agents to monitor specific events (e.g., emails, Slack messages) and act only when needed.
- **Command Or Clicks**: Use native plans for Gmail/Slack/GitHub triggers. Specify start signal and stop conditions.
- **Choice Branch**: Ask agent to save missing info rather than inventing it. Test both appropriate and inappropriate triggers.

### Share Work Safely
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files, sites, or snapshots with colleagues, ensuring proper access controls.
- **Command Or Clicks**: For Codex, open sharing to create a read-only snapshot. Check permissions for shared sites.
- **Choice Branch**: Snapshots do not update with new changes. Share methods/skills if the recipient needs to repeat the work.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Track token consumption across models and tasks to avoid budget overruns.
- **Command Or Clicks**: Use Astra's limit evaluation. Set commands like 'use until 25% of limit'. Check API agreements if using keys.
- **Choice Branch**: Lighter models may save tokens but cost time in correction. Verify task completion before assuming success.

### Stop and Fix Tasks
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: Pause, suspend, or stop tasks if they are stuck or producing bad results.
- **Command Or Clicks**: Ask 'What is happening?' in chat. Suspend target or plan execution for future. Disconnect programs to break connections.
- **Choice Branch**: Do not repeat failed external actions without checking status. Use versioned control to restore previous states.

## Gotchas

### Local tasks require the computer to remain on and awake; sleep mode stops execution.
- **Severity**: blocking
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)

### Cloud tasks do not inherit local files; you must explicitly add materials or use connected locations.
- **Severity**: serious
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Never enter login credentials directly in the chat conversation for browser integrations.
- **Severity**: blocking
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer history includes accessible text which may contain confidential information; disable if necessary.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that AI might interpret as commands (prompt injection); be careful with content sources.
- **Severity**: serious
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)
