## Headline takeaway

Master ChatGPT Work and Codex for professional tasks by choosing cloud vs local execution, editing documents surgically, cleaning spreadsheets, extracting image data, and managing token costs.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Requires Plus or Pro account for Astra model access and computer history features.

### Desktop Application
- **Kind**: tool
- **Note**: Install the ChatGPT desktop app to enable local mode, project folders, and voice chat.

### Mac Computer
- **Kind**: hardware
- **Note**: Computer history and specific local scheduling features are optimized for macOS Pro/Business accounts.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Decide whether to run tasks in the cloud or locally based on file access needs and connectivity. Cloud allows tasks to continue after closing the laptop; local requires the computer to stay awake.
- **Command Or Clicks**: In the desktop app, find the 'local control work' element to switch between cloud and local modes before adding materials.
- **Choice Branch**: Choose cloud if you need to leave the task running remotely. Choose local if the task needs access to specific local folders or applications.

### Prevent Sleep Mode for Local Tasks
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)
- **Action**: If using local mode, ensure your computer remains awake and the application is launched. Prevent sleep mode to avoid stopping long-term local tasks.
- **Command Or Clicks**: Adjust system power settings to prevent sleep during task execution.

### Use Voice Chat for Context
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use voice chat to provide natural context or coordinate tasks. You can start a new voice chat or use dictation within an existing task.
- **Command Or Clicks**: Select 'start voice chat' in supported tasks or press the voice memo button in Code GPT chat.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Ask AI to make specific changes to existing documents rather than rewriting them. Specify which parts to save and which to change.
- **Command Or Clicks**: Say: 'Save headers, save link, change the explanation in this section.'

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Ask AI to clean workbooks by standardizing names, removing duplicates, and formatting dates/currencies. Verify formulas remain editable.
- **Command Or Clicks**: Ask for a cleaned copy with a short explanation of deletions and verify data values.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) to extract specific fields into a table. Specify exact fields and handle missing data explicitly.
- **Command Or Clicks**: Say: 'I want seller column, dates, total amount, currency, category.' Mark empty cells for checks if tax info is missing.

### Verify Research Sources
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and verify sources by publication date and evidence. Request a compact table of evidence before reports.
- **Command Or Clicks**: Say: 'Show me divergence if sources differ. Explain if they use different definitions.'

### Use Browser for Web Tasks
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Let AI use the browser to search and compare information. Provide specific restrictions like dates or locations.
- **Command Or Clicks**: Ask for direct links and details to verify before making choices. Narrow down broad searches during execution.

### Connect Apps via Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins for services like Google Calendar or Slack. Authenticate accounts and start a new task to ensure opportunities are available.
- **Command Or Clicks**: Open plugins, find the service, install it, and connect the account when prompted.

### Manage Projects and Skills
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to keep related tasks and sources together. Create skills (agents.markdown) for reusable workflows.
- **Command Or Clicks**: In the project menu, select 'Edit project' to view or change folders. Use agents.markdown for instructions.

### Enable Computer History
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)
- **Action**: Turn on computer history in settings to allow AI to recall past activities. Be aware this includes accessible text and may contain confidential info.
- **Command Or Clicks**: Go to Settings > Computer History to turn it on. Choose 'only included' programs if desired.

### Select Models and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Choose models (Astra, Soul, Terra, Luna) based on task complexity. Use higher effort for complex reasoning but lower for simple tasks.
- **Command Or Clicks**: Look under the hint field to see model and elements management considerations.

### Use Parallel Agents
- **Timestamp**: [43:16](https://www.youtube.com/watch?v=Risal7sjYms&t=2596)
- **Action**: Ask for parallel work when parts can move independently. Give each agent a clear part of the work and indicate return format.
- **Command Or Clicks**: Say: 'Divide independent research, provide each part the same criteria, give me one unified response.'

### Create Interactive Websites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material to a lightweight website or application. Specify visitor needs and interaction elements.
- **Command Or Clicks**: Ask for specific filters and search fields. Check preview before deploying privately.

### Set Goals and Plans
- **Timestamp**: [49:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2953)
- **Action**: Use goals for long work with clear stopping conditions. Use plans to determine solutions before making changes.
- **Command Or Clicks**: Type /goal or /plan in supported desktop interfaces to describe the result or approach.

### Schedule Repetitive Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Schedule tasks for repetition. Check the saved schedule and first launches to ensure correctness.
- **Command Or Clicks**: Ask for a task and its frequency in simple language. Open planned to check preservation.

### Monitor Events
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Use event triggers (Gmail, Slack) for monitoring. Ask the agent to save missing info and recognize processed elements.
- **Command Or Clicks**: Say: 'Search message with this topic, extract supported dates and let me know only when there is something that needs to be done.'

### Share Work Appropriately
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files, sites, or snapshots based on need. Use Codex sharing for reading-only snapshots.
- **Command Or Clicks**: Open sharing in Codex to select access settings. Check permissions with the recipient.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Track token consumption across models and tasks. Use Astra's limit evaluation to stay within budget.
- **Command Or Clicks**: Say: 'Please use my use of this problems as long as it will not reach 25%, and then Stop.'

### Fix Bad Results
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: If a task is stuck or bad, check status, fix errors specifically, and stop the current implementation if needed.
- **Command Or Clicks**: Ask 'What is happening?' in the chat. Point to real problems with specific details.

## Gotchas

### Local tasks require the computer to remain turned on and awake; sleep mode will stop them.
- **Severity**: blocking
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Cloud tasks do not inherit local files; you must add material to a connected location.
- **Severity**: blocking
- **Timestamp**: [05:06](https://www.youtube.com/watch?v=Risal7sjYms&t=306)

### Never enter credentials in conversation for browser logins; use supported step transmission.
- **Severity**: serious
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer history includes accessible text which may contain confidential information.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that ChatGPT reads as requests, risking prompt injection attacks.
- **Severity**: serious
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)
