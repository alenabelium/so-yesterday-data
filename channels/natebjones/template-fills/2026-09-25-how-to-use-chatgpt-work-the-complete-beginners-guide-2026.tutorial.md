## Headline takeaway

Master ChatGPT Work and Codex for cloud/local task execution, surgical document editing, spreadsheet cleaning, image data extraction, and automated scheduling.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Required for ChatGPT Work access; verify plan includes Astra model and Codex capabilities.

### Desktop Application
- **Kind**: tool
- **Note**: Install the latest version to enable local mode, project management, and computer history features.

### Cloud Connectivity
- **Kind**: knowledge
- **Note**: Understand that cloud tasks continue when offline, while local tasks require your computer to remain on.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Decide where the task runs based on whether you need to leave your laptop or access local files. Cloud tasks continue when the computer is off; local tasks require the machine to stay awake.
- **Command Or Clicks**: In the desktop app, find the 'local control work' element to switch between cloud and local modes.
- **Choice Branch**: Choose Cloud if you want to leave and return later. Choose Local if you need access to specific local folders or applications.

### Prevent Sleep Mode for Local Tasks
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)
- **Action**: If running a long task locally, ensure your computer does not enter sleep mode, which would stop the agent.
- **Command Or Clicks**: Adjust OS power settings to prevent transition to sleep mode during the task duration.
- **Choice Branch**: Heads_up: If the computer sleeps, the local task stops immediately.

### Use Voice for Context and Editing
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use dictation or live voice chat to provide context naturally. On Mac, use screen context to let the AI see what you are discussing.
- **Command Or Clicks**: Select 'start voice chat' in supported tasks or press the voice memo key in Codex Chat.
- **Choice Branch**: Heads_up: Voice chat has limited tool access compared to text; use it for context, not complex file manipulation.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Ask AI to make specific changes to existing documents without rewriting the whole thing. Specify what to save and what to change.
- **Command Or Clicks**: Provide a link to the document and say: 'Save headers, save links, change the explanation in this section.'
- **Choice Branch**: Serious: Always check the actual file after generation to ensure formatting and tables are correct.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Ask AI to clean a workbook by standardizing names, removing duplicates, and fixing date/currency formats. Specify the order of operations.
- **Command Or Clicks**: Ask for a cleaned copy with an explanation of deleted rows and preserved formulas.
- **Choice Branch**: Serious: Verify that formulas remained formulas and were not hardcoded into static values.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload multiple photos (e.g., receipts) to extract specific fields into a table. Always include a source column to link back to the original image.
- **Command Or Clicks**: Upload images and specify fields: 'I want seller, date, total amount, currency, category.'
- **Choice Branch**: Heads_up: Mark empty values as blank, not zero, if tax data is missing from the source.

### Conduct Rigorous Research
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and show divergence in sources. Verify publication dates and evidence quality before trusting conclusions.
- **Command Or Clicks**: Request a compact table of evidence with source, date, and uncertainty for each claim.
- **Choice Branch**: Serious: Do not confuse a long list of sources with conviction; verify key assumptions with real customers.

### Use Browser for Live Data
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Let AI use the browser to search and compare live data (e.g., flight prices). Provide specific constraints like dates and currency.
- **Command Or Clicks**: Ask AI to 'search and compare' with specific criteria, then ask for direct links to verify details.
- **Choice Branch**: Heads_up: Browser sessions are separate from your logged-in browser; you may need to re-authenticate.

### Connect Apps via Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins for services like Google Calendar or Slack. Authenticate accounts and start a new task to ensure access is available.
- **Command Or Clicks**: Open plugins, find the service, install it, and connect your account when prompted.
- **Choice Branch**: Serious: Always check for existing records before creating new ones to avoid duplicates.

### Manage Projects and Skills
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use Projects to group sources, instructions, and tasks. Create Skills (markdown files) for reusable workflows.
- **Command Or Clicks**: In the project menu, select 'Edit project' to add folders or modify instructions.
- **Choice Branch**: Heads_up: Keep skills small and specific; review third-party skills for security before use.

### Schedule Recurring Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Ask AI to schedule a task with a specific frequency and time zone. Check the saved schedule to confirm details.
- **Command Or Clicks**: Say 'schedule this task weekly' and specify the time zone (e.g., '8:00 AM Pacific Time').
- **Choice Branch**: Serious: Local schedules require your computer to be on; cloud schedules do not.

### Monitor with Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Set up monitors for Gmail, Slack, or GitHub that trigger tasks only when specific events occur, saving tokens.
- **Command Or Clicks**: Ask the agent to 'search message with this topic' and only notify if action is needed.
- **Choice Branch**: Heads_up: Monitors do not combine time schedules with event triggers; choose one method.

### Manage Token Costs
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Use Astra for complex tasks and lighter models for stable procedures. Check usage limits and set stop conditions.
- **Command Or Clicks**: Ask the model to 'use my limit as long as it will not reach 25%, and then Stop.'
- **Choice Branch**: Serious: API keys incur separate billing; ensure you know your payment method before running large tasks.

### Stop and Restore Tasks
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: If a task is stuck or wrong, check its status. Stop the implementation if needed, then restore specific previous states.
- **Command Or Clicks**: Ask 'What is happening?' in the chat. To stop, suspend the target or disconnect programs.
- **Choice Branch**: Serious: Disconnecting programs deletes the connection but does not undo changes made by it.

## Gotchas

### Local tasks stop if your computer enters sleep mode. Ensure power settings allow long-running local agents.
- **Severity**: blocking
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Cloud tasks cannot access local files by default. You must explicitly add materials to a connected location.
- **Severity**: blocking
- **Timestamp**: [05:06](https://www.youtube.com/watch?v=Risal7sjYms&t=306)

### Spreadsheets may have hidden errors like dates stored as text or formulas hardcoded as values. Always verify data types.
- **Severity**: serious
- **Timestamp**: [12:46](https://www.youtube.com/watch?v=Risal7sjYms&t=766)

### Computer History is a macOS feature for Pro/Business accounts that records activity. It can capture confidential text input.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that AI might interpret as commands (prompt injection). Be careful with sources.
- **Severity**: serious
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)

### API usage is billed separately from your ChatGPT subscription. Running large tasks via API can incur unexpected costs.
- **Severity**: serious
- **Timestamp**: [01:03:12](https://www.youtube.com/watch?v=Risal7sjYms&t=3792)
