## Headline takeaway

Master ChatGPT Work and Codex for cloud/local tasks, document editing, spreadsheet cleaning, image data extraction, research verification, browser automation, project context, and automated scheduling.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Required for ChatGPT Work, Codex, Astra model access, and project features.

### Desktop Application
- **Kind**: tool
- **Note**: Install the ChatGPT desktop app to enable local mode, file access, and computer history.

### Mac OS (Optional)
- **Kind**: os
- **Note**: Computer History feature is a macOS feature for supported Pro accounts.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Decide between cloud and local execution. Use cloud for tasks you want to continue after closing the laptop. Use local for tasks requiring access to specific folders or applications on your computer.
- **Command Or Clicks**: In desktop app, find 'local control work' element. Ensure computer stays awake for local tasks.
- **Choice Branch**: Cloud: Task continues offline. Local: Requires computer on and app launched.

### Enable Voice Interaction
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use voice dictation for quick hints or live voice chat for complex briefs. On supported Macs, enable screen context to let AI see your window.
- **Command Or Clicks**: Select 'start voice chat' or use dictation. Configure hotkeys in settings.
- **Choice Branch**: Voice chat provides live conversation; dictation transforms language to text.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Connect existing documents (e.g., Google Docs, Word) and instruct AI to make specific changes while preserving headers/links. Always verify the actual file afterward.
- **Command Or Clicks**: Say 'save headers, save link, change explanation'. Check table overflow and formatting.
- **Choice Branch**: Beginners: Ask for a copy first. Experts: Allow editing working file.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Define duplication rules before cleaning. Ask for a cleaned copy with an explanation of deletions. Verify formulas remain formulas and dates are formatted correctly.
- **Command Or Clicks**: Ask 'clean workbook'. Check duplicates, standardize names, verify currency/date formats.
- **Choice Branch**: Standardize names after finding exact duplicates to avoid merging distinct entries.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) and specify fields to extract. Instruct AI to leave cells blank if data is missing rather than guessing zero.
- **Command Or Clicks**: Say 'I want seller column, dates, total amount'. Include source file name in output.
- **Choice Branch**: Specify limits for ambiguous cases like tax amounts.

### Conduct Rigorous Research
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement and show source divergence. Verify publication dates and evidence. Request a compact table of evidence before the final report.
- **Command Or Clicks**: Ask 'show me divergence'. Check source dates and definitions.
- **Choice Branch**: Treat conclusions as hypotheses until verified.

### Use Browser for Live Data
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Let AI use the browser to search and compare live data (e.g., flights). Provide specific constraints like dates and travelers. Ask for direct links to verify.
- **Command Or Clicks**: Use browser tool. Specify 'dates, number of travelers'. Check conditional info.
- **Choice Branch**: Narrow down broad searches during execution.

### Connect Apps via Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins for services like Google Calendar. Name the service in requests. Check for existing records to avoid duplicates before creating new ones.
- **Command Or Clicks**: Open plugins, install service. Use '@' syntax. Check 'existing records'.
- **Choice Branch**: Specify time zones and invite lists explicitly.

### Manage Context with Projects
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to store sources, instructions, and files. Connect current sources instead of flat files for changing info. Be careful with folder selection to avoid context overload.
- **Command Or Clicks**: Select 'Edit project'. Add folders. Name files clearly (avoid 'final').
- **Choice Branch**: Local projects can connect to computer folders.

### Enable Computer History (Mac)
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)
- **Action**: Turn on Computer History in settings for Pro/Business/Enterprise accounts. It records interaction events and accessible text to help find past work. Be aware of privacy implications.
- **Command Or Clicks**: Settings > Computer History > Turn On. Review included programs/websites.
- **Choice Branch**: Disable if working with confidential info without consent.

### Create Reusable Skills
- **Timestamp**: [37:48](https://www.youtube.com/watch?v=Risal7sjYms&t=2268)
- **Action**: Save successful workflows as 'Skills' (markup files like agents.markdown). Test on new inputs to ensure reusability. Check third-party skills for code/instructions.
- **Command Or Clicks**: Create `agents.markdown` in project. Ask AI to help write it.
- **Choice Branch**: Don't convert every clue to a skill; only repeatable, valuable tasks.

### Choose Model and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Select model (Astra, Soul, Terra, Luna) and reasoning effort based on task complexity. Use stronger models for complex analysis; lighter ones for repetitive tasks.
- **Command Or Clicks**: Look under hint field for model/effort controls. Compare results.
- **Choice Branch**: Don't use complex settings for simple reformatting.

### Use Parallel Agents
- **Timestamp**: [43:16](https://www.youtube.com/watch?v=Risal7sjYms&t=2596)
- **Action**: Ask for parallel work when parts can move independently (e.g., searching multiple retailers). Define clear criteria and unified response format.
- **Command Or Clicks**: Say 'Divide independent research'. Specify criteria for each agent.
- **Choice Branch**: Avoid parallel agents if they need to edit the same file.

### Generate Interactive Websites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material to a lightweight website or app. Specify visitor needs and interaction elements (filters, notes). Check preview before private deployment.
- **Command Or Clicks**: Ask 'convert to website'. Specify filters and audience.
- **Choice Branch**: Distinguish between working preview and published site.

### Set Goals and Plans
- **Timestamp**: [48:26](https://www.youtube.com/watch?v=Risal7sjYms&t=2906)
- **Action**: Use Goals for long work with clear stopping conditions. Use Plans to determine solutions before changes. Manage progress via side chat.
- **Command Or Clicks**: Type `/goal` or `/plan`. Define measurable result.
- **Choice Branch**: Goals do not provide broader permissions.

### Schedule Repetitive Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Ask AI to schedule a task. Specify time zone and frequency. Check the saved schedule and run initial tests to ensure usefulness.
- **Command Or Clicks**: Ask 'schedule this weekly'. Check 'Planned' tab.
- **Choice Branch**: Cloud schedules work offline; local schedules need computer on.

### Set Up Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Use event triggers (Gmail, Slack) to monitor for specific conditions. Instruct AI to save missing info and recognize processed items to avoid inefficiency.
- **Command Or Clicks**: Configure trigger in native plan. Specify 'stop' condition.
- **Choice Branch**: Triggers cannot combine with time-based schedules.

### Share Work Appropriately
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files or sites directly. For Codex, share a snapshot (read-only). Share methods/skills for reproducibility. Check permissions carefully.
- **Command Or Clicks**: Open sharing > select access settings. Verify link access.
- **Choice Branch**: Snapshots are not updated with new work.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Track token consumption by model and effort. Use Astra's limit controls ('use up to 25%'). Check API key billing separately from subscription.
- **Command Or Clicks**: Say 'use my limit up to 25%'. Check API agreements.
- **Choice Branch**: Voice operations have separate limits.

### Fix Bad Results
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: If stuck, ask 'status'. If wrong, specify the problem. Stop implementation if needed. Use versioned control to restore previous states.
- **Command Or Clicks**: Ask 'what is happening?'. Suspend goal. Restore specific state.
- **Choice Branch**: Don't repeat external actions without checking status.

## Gotchas

### Local tasks stop if computer sleeps or app closes. Prevent sleep mode for long local tasks.
- **Severity**: blocking
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Cloud tasks do not inherit local files. You must add material to a connected location.
- **Severity**: serious
- **Timestamp**: [05:06](https://www.youtube.com/watch?v=Risal7sjYms&t=306)

### Don't enter credentials in conversation for browser login. Use supported step transmission.
- **Severity**: blocking
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer History records accessible text, which may contain confidential info. Disable if needed.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### Web pages can contain instructions that ChatGPT reads as commands (prompt injection). Be careful with content.
- **Severity**: serious
- **Timestamp**: [01:05:29](https://www.youtube.com/watch?v=Risal7sjYms&t=3929)
