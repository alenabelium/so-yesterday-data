## Headline takeaway

Master ChatGPT Work and Codex for cloud/local tasks, surgical editing, spreadsheet cleaning, image data extraction, research verification, browser automation, project context, model selection, parallel agents, scheduling, and cost.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Required for ChatGPT Work, Codex, and Astra model access.

### Desktop Application
- **Kind**: tool
- **Note**: Install the PC/Mac app to enable local mode and project folder connections.

### MacOS Pro/Business/Enterprise
- **Kind**: hardware
- **Note**: Required for Computer History feature activation on macOS devices.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [02:10](https://www.youtube.com/watch?v=Risal7sjYms&t=130)
- **Action**: Decide between cloud and local execution based on connectivity and file access needs. Use cloud for tasks you want to continue after closing the laptop. Use local for tasks requiring specific computer folders or background scheduling.
- **Command Or Clicks**: In desktop app, find 'local control work' element to switch modes.
- **Choice Branch**: Cloud: Task continues when offline. Local: Requires computer on and awake.

### Prevent Sleep Mode for Local Tasks
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: If using local mode, ensure the computer remains turned on and available. Prevent sleep mode during long tasks to avoid stopping execution.
- **Command Or Clicks**: Adjust OS power settings to prevent sleep during task duration.
- **Choice Branch**: Blocking: Local tasks stop if computer sleeps.

### Manage File Access for Cloud Tasks
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)
- **Action**: Cloud tasks do not inherit local files. Add material to a connected location accessible by the agent before leaving the task.
- **Command Or Clicks**: Upload files to cloud storage or provide direct links.
- **Choice Branch**: Serious: Cloud agent cannot access local desktop files.

### Use Voice Interaction
- **Timestamp**: [05:06](https://www.youtube.com/watch?v=Risal7sjYms&t=306)
- **Action**: Start voice chat for live conversation or use dictation for quick text input. Use voice to provide context, confirm results, or change direction without typing.
- **Command Or Clicks**: Select 'start voice chat' or press voice memo key.
- **Choice Branch**: Heads_up: Voice chat has limited tool access compared to typed queries.

### Edit Documents Surgically
- **Timestamp**: [07:59](https://www.youtube.com/watch?v=Risal7sjYms&t=479)
- **Action**: Connect to existing documents in Google Docs or Word. Specify exact parts to change, save headers, or add comments rather than rewriting the whole document.
- **Command Or Clicks**: Provide link to file and specific instructions for sections.
- **Choice Branch**: Heads_up: Check formatting and table overflow after changes.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Define duplication rules before standardizing names. Ask for a cleaned copy with an explanation of deletions. Verify formulas remain formulas.
- **Command Or Clicks**: Ask AI to 'clean the file' and specify 'keep formulas'.
- **Choice Branch**: Serious: Standardizing names before finding duplicates can merge distinct records.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) and specify required fields. Instruct AI to leave cells blank if data is missing, rather than guessing zero.
- **Command Or Clicks**: Upload images and prompt: 'I want seller column, dates, total amount'.
- **Choice Branch**: Heads_up: Empty values and zeros are different for tax purposes.

### Verify Research Sources
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask for a compact table of evidence including source, date, and uncertainty. Check publication dates to avoid outdated information.
- **Command Or Clicks**: Prompt: 'Show me divergence in sources' and 'Check publication dates'.
- **Choice Branch**: Serious: Recent pages may contain old information.

### Use Browser for Live Data
- **Timestamp**: [23:52](https://www.youtube.com/watch?v=Risal7sjYms&t=1432)
- **Action**: Use browser integration to search and compare live data. Provide specific restrictions (dates, travelers) to narrow results.
- **Command Or Clicks**: Ask AI to 'search' and 'compare' using browser tools.
- **Choice Branch**: Heads_up: Browser sessions are separate from local login.

### Connect Plugins
- **Timestamp**: [27:20](https://www.youtube.com/watch?v=Risal7sjYms&t=1640)
- **Action**: Open plugins, find the service, install it, and connect your account. Start a new task to ensure opportunities are available.
- **Command Or Clicks**: Click 'plugins', search service, install, connect account.
- **Choice Branch**: Heads_up: Some connections authenticate only on first use.

### Manage Project Context
- **Timestamp**: [30:09](https://www.youtube.com/watch?v=Risal7sjYms&t=1809)
- **Action**: Use projects to keep related tasks and sources together. Connect current sources for changing information, not flat files.
- **Command Or Clicks**: Open project menu, select 'Edit project', add folders.
- **Choice Branch**: Heads_up: Local projects can connect to multiple folders.

### Enable Computer History
- **Timestamp**: [33:59](https://www.youtube.com/watch?v=Risal7sjYms&t=2039)
- **Action**: On supported Macs, enable Computer History in settings to allow AI to view local files and recordings. Check included programs before turning on.
- **Command Or Clicks**: Settings > Computer History > Turn On.
- **Choice Branch**: Serious: Includes accessible text which may contain confidential info.

### Select Model and Effort
- **Timestamp**: [39:44](https://www.youtube.com/watch?v=Risal7sjYms&t=2384)
- **Action**: Choose model based on task complexity. Use Astra for demanding work, Soul for large batches, Terra for everyday tasks. Adjust effort level.
- **Command Or Clicks**: Look under hint field to select model and effort.
- **Choice Branch**: Heads_up: Stronger settings do not fix wrong source data.

### Use Parallel Agents
- **Timestamp**: [42:20](https://www.youtube.com/watch?v=Risal7sjYms&t=2540)
- **Action**: Ask for parallel work when parts can move independently. Give each agent a clear part of the work and specify return format.
- **Command Or Clicks**: Prompt: 'Divide independent research, provide unified response'.
- **Choice Branch**: Heads_up: Avoid parallel agents if they need same unresolved solution.

### Create Interactive Sites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material to a lightweight website. Specify visitor needs, filters, and interaction elements for usability.
- **Command Or Clicks**: Prompt: 'Convert to website' with specific filter requirements.
- **Choice Branch**: Heads_up: Check preview before private deployment.

### Use Goals for Long Tasks
- **Timestamp**: [48:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2893)
- **Action**: Use goals for results needing several rounds of work. Type /goal and describe result. Manage progress via side chat.
- **Command Or Clicks**: Type '/goal' in supported desktop interfaces.
- **Choice Branch**: Heads_up: Goals do not provide broader permissions.

### Schedule Repetitive Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Ask for task repetition in simple language. Check saved schedule for time and instructions. Specify time zone.
- **Command Or Clicks**: Prompt: 'Repeat this weekly at 8:00 AM Pacific Time'.
- **Choice Branch**: Heads_up: Cloud schedules work offline; local schedules need computer on.

### Set Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Use native plans for Gmail, Slack, or GitHub triggers. Define specific start signals and final conditions to stop monitoring.
- **Command Or Clicks**: Configure trigger in relevant app settings within ChatGPT.
- **Choice Branch**: Heads_up: Triggers cannot combine with time-based schedules.

### Share Work Appropriately
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files or sites directly. For Codex, create a reading-only snapshot. Check permissions before sharing.
- **Command Or Clicks**: Open sharing settings, select access level, send link.
- **Choice Branch**: Serious: Snapshots do not update with new changes.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Check token consumption for large tasks. Use Astra's limit commands to react to usage. Plan frequency based on information change rate.
- **Command Or Clicks**: Prompt: 'Use my limit as long as it will not reach 25%'.
- **Choice Branch**: Serious: API keys charge separately from subscription.

### Fix Bad Results
- **Timestamp**: [01:03:12](https://www.youtube.com/watch?v=Risal7sjYms&t=3792)
- **Action**: If task is stuck, ask status. If result is bad, point to specific problem. Stop current implementation if necessary.
- **Command Or Clicks**: Prompt: 'What is happening?' or 'Stop current implementation'.
- **Choice Branch**: Heads_up: External actions may have succeeded despite unclear status.
