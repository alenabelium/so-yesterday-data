## Headline takeaway

Master ChatGPT Work and Codex for cloud tasks, surgical editing, spreadsheet cleaning, image extraction, research verification, and automated scheduling.

## Prerequisites

### OpenAI Account
- **Kind**: account
- **Note**: Pro, Business, or Enterprise tier required for Astra model and computer history features.

### Desktop Application
- **Kind**: tool
- **Note**: Required for local mode, project folders, and computer history access on macOS.

## Steps

### Choose Cloud vs Local Environment
- **Timestamp**: [03:23](https://www.youtube.com/watch?v=Risal7sjYms&t=203)
- **Action**: Select cloud for tasks you leave running while away; select local for tasks needing folder access or background scheduling on your machine.
- **Command Or Clicks**: Find the element 'local control work' in the desktop application interface.
- **Choice Branch**: Cloud if you need to close the laptop; Local if you need specific computer files.

### Prevent Sleep Mode for Local Tasks
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)
- **Action**: Ensure your computer stays awake and the application is launched during long local tasks to avoid interruption.
- **Command Or Clicks**: Disable sleep mode settings on your OS while the task runs.
- **Choice Branch**: N/A

### Use Voice for Context and Editing
- **Timestamp**: [06:07](https://www.youtube.com/watch?v=Risal7sjYms&t=367)
- **Action**: Use dictation or live voice chat to provide context, ask questions, or guide edits without typing.
- **Command Or Clicks**: Select 'start voice chat' or use external tools like Whisper.
- **Choice Branch**: Dictation for quick hints; Voice Chat for complex briefs.

### Edit Documents Surgically
- **Timestamp**: [08:56](https://www.youtube.com/watch?v=Risal7sjYms&t=536)
- **Action**: Ask AI to make specific changes to an existing file, specifying what to keep and what to change.
- **Command Or Clicks**: Provide a link to the connected document and specify 'save headers, change explanation'.
- **Choice Branch**: Request a copy first for safety; edit directly once confident.

### Clean Messy Spreadsheets
- **Timestamp**: [11:42](https://www.youtube.com/watch?v=Risal7sjYms&t=702)
- **Action**: Instruct AI to clean duplicates, standardize names, and format dates/currencies in a workbook.
- **Command Or Clicks**: Ask for a cleaned copy with an explanation of deleted rows.
- **Choice Branch**: Specify if formulas must remain formulas or be hardcoded.

### Extract Data from Images
- **Timestamp**: [15:15](https://www.youtube.com/watch?v=Risal7sjYms&t=915)
- **Action**: Upload photos (e.g., receipts) and specify the exact fields to extract into a table.
- **Command Or Clicks**: Specify fields like 'seller', 'date', 'total amount', 'currency'.
- **Choice Branch**: Leave cells blank if data is missing; do not guess.

### Verify Research Sources
- **Timestamp**: [18:53](https://www.youtube.com/watch?v=Risal7sjYms&t=1133)
- **Action**: Ask AI to maintain disagreement, show source divergence, and verify publication dates.
- **Command Or Clicks**: Request a compact table of evidence with source, date, and uncertainty.
- **Choice Branch**: Mark hypotheses as such; do not treat them as facts.

### Use Browser for Live Data
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)
- **Action**: Let AI browse websites to get current information, but verify links and details yourself.
- **Command Or Clicks**: Ask for direct links and details to check before making choices.
- **Choice Branch**: Narrow down broad searches during execution.

### Connect Apps via Plugins
- **Timestamp**: [28:11](https://www.youtube.com/watch?v=Risal7sjYms&t=1691)
- **Action**: Install plugins for services like Google Calendar to allow AI to read/write data.
- **Command Or Clicks**: Open plugins, find the service, install, and connect account.
- **Choice Branch**: Start a new task after installation to ensure access.

### Manage Projects and Skills
- **Timestamp**: [30:57](https://www.youtube.com/watch?v=Risal7sjYms&t=1857)
- **Action**: Use projects to store sources and instructions; create skills for reusable workflows.
- **Command Or Clicks**: Edit project to add folders or set basic folder.
- **Choice Branch**: Archive completed work; use skills for repetitive tasks.

### Enable Computer History
- **Timestamp**: [33:59](https://www.youtube.com/watch?v=Risal7sjYms&t=2039)
- **Action**: Turn on computer history in settings to allow AI to recall past activities.
- **Command Or Clicks**: Go to Settings > Computer History and toggle on.
- **Choice Branch**: Review included programs/websites before enabling.

### Select Model and Effort
- **Timestamp**: [40:55](https://www.youtube.com/watch?v=Risal7sjYms&t=2455)
- **Action**: Choose models like Astra for complex tasks or Terra for everyday use; adjust reasoning effort.
- **Command Or Clicks**: Look under the hint field to see model and elements management.
- **Choice Branch**: Use more reflections only for controversial evidence or complex plans.

### Use Parallel Agents
- **Timestamp**: [43:16](https://www.youtube.com/watch?v=Risal7sjYms&t=2596)
- **Action**: Delegate independent parts of a task to multiple agents for parallel processing.
- **Command Or Clicks**: Ask the main agent to divide research and provide a unified response.
- **Choice Branch**: Avoid parallel agents if they need to coordinate closely.

### Create Interactive Sites
- **Timestamp**: [45:52](https://www.youtube.com/watch?v=Risal7sjYms&t=2752)
- **Action**: Convert assignment material into a lightweight website or application for interactive viewing.
- **Command Or Clicks**: Provide specifics on visitor needs and filtering options.
- **Choice Branch**: Check preview before deploying privately.

### Set Goals and Plans
- **Timestamp**: [49:13](https://www.youtube.com/watch?v=Risal7sjYms&t=2953)
- **Action**: Use goals for long work with clear stopping conditions; use plans to determine solutions.
- **Command Or Clicks**: Type /goal or /plan in supported desktop interfaces.
- **Choice Branch**: Ensure instructions have a recognizable ending.

### Schedule Recurring Tasks
- **Timestamp**: [51:38](https://www.youtube.com/watch?v=Risal7sjYms&t=3098)
- **Action**: Ask AI to schedule repetitive tasks, specifying frequency and time zone.
- **Command Or Clicks**: Open planned to check if the task was preserved.
- **Choice Branch**: Use separate launches for new reports; existing chats for ongoing investigation.

### Set Up Event Triggers
- **Timestamp**: [54:34](https://www.youtube.com/watch?v=Risal7sjYms&t=3274)
- **Action**: Configure agents to monitor specific events (e.g., emails) and notify only when action is needed.
- **Command Or Clicks**: Narrow down triggers by sender or topic in Gmail/Slack.
- **Choice Branch**: Specify a final condition to stop the monitor.

### Share Work Appropriately
- **Timestamp**: [57:27](https://www.youtube.com/watch?v=Risal7sjYms&t=3447)
- **Action**: Share files, sites, or methods based on whether the recipient needs results or the process.
- **Command Or Clicks**: Open sharing in Codex to create a read-only snapshot.
- **Choice Branch**: Check permissions and audience before sharing.

### Monitor Token Usage
- **Timestamp**: [01:00:26](https://www.youtube.com/watch?v=Risal7sjYms&t=3626)
- **Action**: Track token consumption, especially with Astra's new evaluation features, to manage costs.
- **Command Or Clicks**: Use commands like 'use my limit... then Stop' if supported.
- **Choice Branch**: Check time reset and expense controls.

### Fix Bad Results
- **Timestamp**: [01:04:03](https://www.youtube.com/watch?v=Risal7sjYms&t=3843)
- **Action**: Ask for status, point out specific problems, or stop the task if external actions failed.
- **Command Or Clicks**: Ask 'What is happening?' in the chat.
- **Choice Branch**: Suspend the target to pause; disconnect programs to delete connection.

## Gotchas

- **Severity**: blocking
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=Risal7sjYms&t=250)

### Cloud tasks do not inherit local files; you must add material to a connected location.
- **Severity**: serious
- **Timestamp**: [05:06](https://www.youtube.com/watch?v=Risal7sjYms&t=306)

### Do not enter credentials in conversation; use supported step transmission for login.
- **Severity**: blocking
- **Timestamp**: [25:01](https://www.youtube.com/watch?v=Risal7sjYms&t=1501)

### Computer history includes accessible text, which may contain confidential information.
- **Severity**: serious
- **Timestamp**: [35:07](https://www.youtube.com/watch?v=Risal7sjYms&t=2107)

### External web pages can contain instructions that ChatGPT might interpret as commands.
