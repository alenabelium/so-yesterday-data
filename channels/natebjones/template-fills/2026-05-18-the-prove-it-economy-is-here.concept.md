## TL;DR

The internet economy has shifted from attention to interpretation, where AI agents mediate consumer and hiring decisions. To survive, individuals and brands must build a 'truth layer' of structured, factual data that allows agents to verify claims, while simultaneously cultivating strong offline human connections to drive brand loyalty.

## The argument

### The Shift to Interpretation
- **Anchor Timestamps**: ['00:00:00']
- **Claim**: The economy has moved from an attention model (shouting for eyeballs) to an interpretation model where AI agents filter all decisions. Success requires positioning for AI agents, not just humans.
- **Role**: definition

### Building the Truth Layer
- **Anchor Timestamps**: ['00:05:51']
- **Claim**: Marketers and individuals must provide a 'truth layer' of high-fidelity, structured data (like JSON schemas) that proves specific claims. Without this, agents flatten offerings into the internet average.
- **Role**: evidence

### The Offline Anchor
- **Anchor Timestamps**: ['00:11:38']
- **Claim**: Human memory and offline events create brand loyalty that constrains agent behavior. Strong human connections prevent agents from averaging out a brand by prompting specific, loyal queries.
- **Role**: counter

### Synthesis of Dual Internets
- **Anchor Timestamps**: ['00:15:05']
- **Claim**: The future requires reinforcing both the human-facing memory layer and the agent-facing truth layer. AI washing fails because it lacks the substantive data agents need to verify claims.
- **Role**: synthesis

## Evidence and caveats

The speaker cites buying a sound system via chat with Claude and ChatGPT as a personal example of agent-mediated shopping. He notes that back-office automation (like AI writing resumes) is 'table stakes' and insufficient for differentiation. A key caveat is that agents need 'opinionated' data to avoid flattening brands; vague marketing fails. The speaker also warns that while agents mediate, humans still apply preference, making offline memory critical.
