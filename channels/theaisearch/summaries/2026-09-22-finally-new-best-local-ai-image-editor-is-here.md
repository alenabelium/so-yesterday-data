# Finally! New best local AI image editor is here

## Executive Summary

The video introduces Qwen Image 2.1, a new open-source local AI image generator and editor capable of high-fidelity text-to-image generation, complex editing, and transparent background output. The presenter demonstrates how to install and configure the model using Comfy UI, detailing the necessary model downloads and workflow setups for various tasks like background removal and character consistency. Special attention is given to optimizing performance for low-VRAM hardware through quantized GGUF models, ensuring accessibility for users with limited GPU resources. Finally, the video clarifies the licensing terms, confirming that users retain commercial rights to their generated outputs despite the model's non-commercial license.

## Key Points

- Qwen Image 2.1 offers advanced capabilities including text-to-image generation, multi-reference image editing, and native alpha channel output for transparent images [00:01:32](https://www.youtube.com/watch?v=BaE6UBfNdQk&t=92)
- Installation requires Comfy UI and specific model downloads, with options like INT8 quantization allowing operation on GPUs with as little as 8 GB of VRAM [00:04:10](https://www.youtube.com/watch?v=BaE6UBfNdQk&t=250)
- Users with less than 4 GB of VRAM can utilize highly compressed GGUF models (e.g., Q3) via custom Comfy UI nodes to run the model effectively [00:15:45](https://www.youtube.com/watch?v=BaE6UBfNdQk&t=945)
- The official license prohibits commercial use of the model weights, but users retain full rights to the images and content generated by the AI [00:17:57](https://www.youtube.com/watch?v=BaE6UBfNdQk&t=1077)
