# New #1 open source AI model is here! FABLE LEVEL

## Executive Summary

Moonshot AI has released Kimmy K3, a massive 2.8 trillion parameter open-source model that rivals top closed frontier models like GPT 5.6 and Claude Fable in intelligence and performance. The video demonstrates its capabilities through complex agentic workflows, including building physics simulations, 3D Blender animations, and interactive games, highlighting its ability to handle long-horizon tasks autonomously. Benchmarks indicate Kimmy K3 leads in agentic coding benchmarks and offers superior cost-efficiency compared to its proprietary competitors. With a million-token context window and plans for open-weight release, the model represents a significant shift in the open-source AI landscape.

## Key Points

- Kimmy K3 is a 2.8 trillion parameter open-source model that matches the performance of closed frontier models like GPT 5.6 and Claude Fable in agentic coding and reasoning tasks [00:24:25](https://www.youtube.com/watch?v=bEnE5pbpe_Q&t=1465).
- The model excels in long-horizon agentic workflows, successfully creating complex outputs like a liquid splash simulator, a 3D V8 engine in Blender, and a playable 3D piano from single prompts [00:02:50](https://www.youtube.com/watch?v=bEnE5pbpe_Q&t=170).
- Kimmy K3 demonstrates superior cost-efficiency and lower hallucination rates compared to GPT 5.6 and Claude Fable, while leading in code arena benchmarks [00:26:52](https://www.youtube.com/watch?v=bEnE5pbpe_Q&t=1612).
- The model features a 1 million token context window and will be released as open weights on July 27th, accessible via Kimmy Code, desktop apps, and API [00:24:25](https://www.youtube.com/watch?v=bEnE5pbpe_Q&t=1465). [MM:SS](https://www.youtube.com/watch?v=bEnE5pbpe_Q&t=SECONDS)
