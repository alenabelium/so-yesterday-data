## Headline takeaway

Heart Moola brings open-source music generation close to Suno, while PixVerse R1 debuts real-time interactive video.

## Tools covered

### Show UI Aloha
- **Vendor**: Show UI
- **Category**: agent
- **Timestamp**: [01:23](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=83)
- **Why It Matters**: An AI agent that learns computer tasks by watching human demonstrations, then autonomously replicates similar workflows like booking flights or editing spreadsheets.
- **Sota Comparison**: Outperforms leading agents like UI TARS and Claude 4 Sonnet on taught workflows.
- **Sota Band**: beats
- **Access Constraint**: Open-source, requires LLM API key

### Nova SR
- **Vendor**: Nova
- **Category**: audio
- **Timestamp**: [03:27](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=207)
- **Why It Matters**: A 50KB audio upscaler that enhances quality at 3500x real-time speed, running on consumer GPUs.
- **Sota Comparison**: On par with models 5000x larger, outperforms slower and larger competitors.
- **Sota Band**: beats
- **Access Constraint**: Open-source, free Hugging Face Space

### VerseCrafter
- **Vendor**: Tencent
- **Category**: video
- **Timestamp**: [05:10](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=310)
- **Why It Matters**: Generates videos from a single image with 3D control over camera movements and object trajectories, editable in Blender.
- **Sota Comparison**: More coherent and higher quality than competitors like U May and Uni 3C.
- **Sota Band**: beats
- **Access Constraint**: Open-source, includes Blender add-on

### UniSH
- **Vendor**: UniSH
- **Timestamp**: [08:41](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=521)
- **Why It Matters**: Creates 3D models of scenes with humans from video, including camera position and human pose, enabling full 3D rendering.
- **Sota Comparison**: Handles shaky cameras and complex movements accurately.
- **Sota Band**: inferred
- **Access Constraint**: Open-source

### Show UI Pi
- **Vendor**: Show UI
- **Category**: agent
- **Timestamp**: [09:46](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=586)
- **Why It Matters**: Enables AI agents to perform smooth mouse drag operations, solving slider CAPTCHAs and manipulating video editors.
- **Sota Comparison**: Outperforms proprietary models like Gemini on computer use tasks, especially PowerPoint and Premiere.
- **Sota Band**: beats
- **Access Constraint**: Open-source, missing documentation

### AnyDepth
- **Vendor**: AnyDepth
- **Category**: tool
- **Timestamp**: [11:22](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=682)
- **Why It Matters**: A depth estimator that enhances detail and fidelity in images and videos, running faster with lower latency than competitors.
- **Sota Comparison**: Best scores on benchmarks, faster and more memory-efficient than DPT.
- **Sota Band**: beats
- **Access Constraint**: Open-source

### Flux 2 Klein
- **Vendor**: Flux
- **Category**: image
- **Timestamp**: [13:30](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=810)

- **Access Constraint**: Open-source

### Vibe

- **Category**: image

- **Sota Band**: parity
- **Access Constraint**: Open-source, free Hugging Face demo

### Shape-R
- **Vendor**: Meta
- **Timestamp**: [18:33](https://www.youtube.com/watch?v=eHMVifFMq0Q&t=1113)
- **Why It Matters**: Creates metric-accurate individual 3D models of each object in a scene from phone photos or videos, enabling separate editing.
- **Sota Comparison**: Unlike traditional generators, produces individual object models with correct size and position.
- **Sota Band**: new
- **Access Constraint**: Open-source

### Heart Moola
- **Vendor**: Heart Moola
- **Category**: music

## Wider context

This week's releases push the boundaries of real-time and interactive AI across multiple modalities. The trend is toward smaller, faster models that run locally, from Nova SR's 50KB audio upscaler to the 100M parameter TTS, democratizing access. Simultaneously, agents like Show UI Pi and Aloha are moving beyond simple clicks to complex, human-like interactions, while music generation closes the gap with closed-source leaders.
