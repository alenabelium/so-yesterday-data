## Headline takeaway

Nvidia releases Earth 2 for open-source weather forecasting, while Google's Project Genie and Lingbot World enable real-time interactive AI video games.

## Tools covered

### Earth 2
- **Vendor**: Nvidia
- **Category**: weather
- **Timestamp**: [00:30](https://www.youtube.com/watch?v=7E1Utay5q9k&t=30)
- **Why It Matters**: Open-source AI weather forecasting models that are 90% faster than traditional physics-based methods, predicting storms and temperature up to 15 days in advance.
- **Sota Comparison**: Beats traditional physics-based models in speed and accuracy for medium-range and nowcasting forecasts.
- **Sota Band**: beats
- **Access Constraint**: Open-source

### MOA
- **Vendor**: Open-source
- **Category**: video
- **Timestamp**: [02:39](https://www.youtube.com/watch?v=7E1Utay5q9k&t=159)
- **Why It Matters**: Open-source video generator with native audio, using a mixture of experts model with 32 billion parameters to produce 360p/720p videos.
- **Sota Comparison**: Claims to outperform LTX-2 in audio sync benchmarks, though the 77GB model size limits consumer accessibility.
- **Sota Band**: parity
- **Access Constraint**: Open-source (High VRAM)

### Gemini 3 Flash
- **Vendor**: Google
- **Category**: multimodal
- **Timestamp**: [04:34](https://www.youtube.com/watch?v=7E1Utay5q9k&t=274)
- **Why It Matters**: Introduces agentic vision capabilities, allowing the model to proactively zoom, crop, and annotate images via Python code to improve OCR and analysis accuracy by 5-10%.
- **Sota Comparison**: Enhances standard multimodal understanding with active visual manipulation, a feature not present in standard vision models.
- **Sota Band**: new
- **Access Constraint**: Free via API

### Hunyuan Image 3.0 Instruct
- **Vendor**: Tencent
- **Category**: image
- **Timestamp**: [06:00](https://www.youtube.com/watch?v=7E1Utay5q9k&t=360)
- **Why It Matters**: Multimodal image editor with native chain-of-thought reasoning, allowing for complex edits like perspective changes and object replacement with high prompt adherence.
- **Sota Comparison**: Offers higher quality and better instruction following than the base Hunyuan Image 3, rivaling closed-source editors.
- **Sota Band**: beats
- **Access Constraint**: Open-source (High VRAM)

### OpenClaw
- **Vendor**: OpenClaw
- **Category**: agent
- **Timestamp**: [09:39](https://www.youtube.com/watch?v=7E1Utay5q9k&t=579)
- **Why It Matters**: Open-source agent framework that lives on-device or server, enabling 24/7 interaction via WhatsApp/Telegram and forming social communities like Moltbook.
- **Sota Comparison**: Represents a shift towards persistent, socially interactive AI agents rather than transient chat interfaces.
- **Sota Band**: new
- **Access Constraint**: Open-source

### Project Genie
- **Vendor**: Google DeepMind
- **Category**: video
- **Timestamp**: [13:39](https://www.youtube.com/watch?v=7E1Utay5q9k&t=819)
- **Why It Matters**: Generates real-time, interactive playable worlds from text or image prompts with visual memory and emergent physics behaviors.
- **Sota Comparison**: Sets a new standard for real-time interactive video generation, though limited to 60-second clips and paid access.
- **Sota Band**: new
- **Access Constraint**: Paid ($250/mo)

### Lingbot World
- **Vendor**: Open-source
- **Category**: video
- **Timestamp**: [18:24](https://www.youtube.com/watch?v=7E1Utay5q9k&t=1104)

- **Sota Comparison**: Matches the interactivity of Genie but requires 160GB VRAM, making it less accessible than closed competitors.
- **Sota Band**: parity
- **Access Constraint**: Open-source (High VRAM)

### Lucy 2

## Wider context

The week highlights a divergence in AI capabilities: open-source models like Earth 2 and Qwen 3 Max are achieving parity or beating closed competitors in specialized domains like weather and reasoning. Meanwhile, interactive video generation is becoming a key battleground, with Google's Project Genie and open-source Lingbot World pushing the boundaries of real-time, playable AI worlds.
