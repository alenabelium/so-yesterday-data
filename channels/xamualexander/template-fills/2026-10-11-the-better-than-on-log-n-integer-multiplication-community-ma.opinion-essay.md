## Thesis

The Beyond Enlil community's iterative AI-generated improvements to integer multiplication show that mathematics is becoming a contingent, human-driven process, challenging the Platonic ideal of eternal mathematical truth.

## Argument

The mechanism is the community itself. OpenAI's initial AI-generated proof on October 6th, 2026, achieved a kappa of 2^-182, a tiny improvement over O(n log n). Within days, the community on the 'Beyond Enlil' website had improved this to kappa = 1.48 * 2^-11, a dramatic leap. This is not a single breakthrough but a rapid, collaborative, version-controlled process. The site functions like a GitHub repository for mathematical proofs, with pull requests, comments, and references to prior contributions as if they were scientific papers. This is mathematics done 'post-journal system,' using Git as I've long advocated. The key philosophical point is that the limit of these kappas, kappa_infinity, is not a Platonic ideal. It is contingent on human choices—what people decide to upload next. It is a physical number, not a mathematical one. To make it a mathematical question, you must fix the AI and the proof checker. For example, fixing a specific AI like GPT-6 and Lean 4.34.1, you can define kappa_infinity_prime as the supremum of all kappas provable by that fixed system. This is a purely mathematical object, but the resulting algorithm is a 'galactic algorithm'—totally impractical, requiring enormous time to find the best algorithm for any given input size. This illustrates the tension between the practical, contingent world of community-driven mathematics and the abstract, eternal realm of Platonic ideals.

## Counterpoints

- One might object that kappa_infinity is not a well-defined mathematical object because it depends on unpredictable human actions, but this is precisely the point: it is a physical, not mathematical, quantity.
- Another objection is that the meta-algorithm using an oracle is not a real algorithm, but it serves to illustrate the conceptual difference between a mathematical result and a physical process.
- A third counterpoint is that fixing an AI and Lean version makes the question purely mathematical, but the resulting algorithm is so impractical as to be useless, highlighting the gap between theory and practice.
