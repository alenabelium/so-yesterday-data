## Thesis

The grassroots, version-controlled improvement of integer multiplication algorithms on Beyond Enlil shows that future mathematics will be a communal, contingent process, not a fixed Platonic ideal.

## Argument

The mechanism is the community itself. On October 6th, OpenAI published an AI-generated proof that integer multiplication can be done in O(n log^(1-2^-182) n) time. The very next day, the Beyond Enlil community began improving the exponent, and within days it had dropped from 2^-182 to 1.48*2^-11. This is not a single breakthrough but a continuous, collaborative effort, with contributors filing pull requests that reference each other like scientific papers. The language they use—'dirty entrances,' 'entrance rank units,' 'transported entrances'—is a new technical vocabulary invented on the fly. This is mathematics as a living, social process, not a static body of eternal truths.

The philosophical stakes are clear: the limit of these improvements, kappa_infinity, is not a Platonic ideal. It depends on what humans choose to upload to the website, so it is a physical, contingent number, not an eternal one. The host proves this by showing that achieving kappa_infinity requires an oracle—a black box that predicts human behavior—which is not a mathematical algorithm. To get a purely mathematical result, you must fix the AI and the proof checker, turning the process into a deterministic enumeration. But even then, the resulting algorithm is a 'galactic algorithm,' utterly impractical. The point is not efficiency; it is that mathematics is being done in a new way, and this changes what we mean by mathematical truth.

## Counterpoints

- One might object that kappa_infinity is still a well-defined mathematical limit, but the host argues it is contingent on human choices, making it a physical, not mathematical, number.
- Another objection is that the meta-algorithm achieving kappa_infinity is not a real algorithm because it requires an oracle for human behavior, so it does not settle the open question.
- A third counterpoint is that fixing the AI and Lean version makes the problem purely mathematical, but the host notes this is impractical and yields a 'galactic algorithm' that is useless in practice.
