## TL;DR

Numbers vote on function comparisons; majority axioms that stay dictator-free force infinite voter sets, yielding free ultrafilters and the hyperreals.

## The argument

### Define majorities by voting power
- **Anchor Timestamps**: ['00:03:36']
- **Claim**: A set of voters is a majority if its support guarantees a win regardless of others. This definition is the substrate for all later axioms.
- **Role**: definition

### Derive the first three axioms
- **Anchor Timestamps**: ['00:03:36']
- **Claim**: Non-triviality (empty set loses), monotonicity (supersets of majorities are majorities), and unambiguity (complement of a non-majority is a majority) follow from intuitive election fairness.
- **Role**: evidence

### Add transitivity via intersections
- **Anchor Timestamps**: ['00:06:45']
- **Claim**: To force coherent comparisons, require intersections of majorities to be majorities. This axiom is counterintuitive for finite elections but unlocks infinite voter sets.
- **Role**: evidence

### Escape Arrow's dictator
- **Anchor Timestamps**: ['00:10:26']
- **Claim**: Arrow's theorem forces a dictator for finite voters, but with infinitely many naturals we can add a fifth axiom — no singleton majority — and still satisfy all five.
- **Role**: synthesis

### Name the free ultrafilter
- **Anchor Timestamps**: ['00:09:17']
- **Claim**: Elite mathematicians phrase the existence theorem as 'there exists a free ultrafilter on V' for any infinite V. This is the formal object our axioms describe.
- **Role**: definition

## Evidence and caveats

The sine/cosine example (00:01:26) shows the voting setup. The identity function yields an infinite hyperreal (00:14:36); 1/x yields an infinitesimal (00:15:59). The host calls the dictator solution 'stupid and trivial' (00:07:49) and leaves several proofs as exercises, e.g., that an infinitude beats a finitude (00:14:36). He also notes the ordering is not linear until equivalence classes blur non-equal functions (00:11:54).
