## Thesis

The Riemann at Home project marks a new era of collaborative mathematics where AI-generated proofs are verified by crowds, and software itself becomes obsolete.

## Argument

The project replaces traditional software downloads with a plain-English prompt for AI agents, showing that software itself is becoming obsolete. Instead of publishing a program, the site gives a query that instructs an agent to clone the repo, build it, and run the verification, with the agent posting progress automatically. This is why, despite AI supposedly revolutionizing software, we don't see a flood of new apps—the software is being replaced by prompts. The verification is redundant, since the Lean proof has already been certified by the Lean and mathlib communities, but the crowd-sourced checking builds trust and guards against the perception of a scam or conspiracy. Each independent check adds confidence, and the leaderboard tracks who has verified which parts, with the most dedicated even reproducing the export certificate. This is a grassroots, collaborative effort that contrasts with the elitist, individualistic math of the past, and it's a sign of a more exciting, accessible future for mathematics.

## Counterpoints

- The proof is already verified by the Lean and mathlib communities, so the project is unnecessary.
- The Riemann hypothesis is often oversimplified as being about prime numbers, but it's actually about the zeros of a function.
