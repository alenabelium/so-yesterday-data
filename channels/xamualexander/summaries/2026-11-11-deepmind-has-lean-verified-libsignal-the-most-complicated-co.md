# DeepMind has LEAN-verified libsignal, the most complicated codebase to be verified to date

## Executive Summary

DeepMind's AlphaProof Code framework has formally verified key security properties of libsignal, the cryptographic protocol underlying Signal and other messaging apps, at the machine code level—a first for a widely deployed, unmodified implementation. The multi-agent system generated 6.5 million lines of Lean proofs in four weeks, a task that historically took years. While the achievement is significant for practical security, the presenter argues it represents a routine application of existing AI techniques rather than a fundamental research breakthrough, noting the hype and academic framing.

## Key Points

- DeepMind's AlphaProof Code framework verified libsignal's security properties at the machine code level, a first for a widely deployed protocol. [00:01:17](https://www.youtube.com/watch?v=tMHyp1_n8wY&t=77)
- The verification process took four weeks and generated 6.5 million lines of Lean proofs, with only 1% of the codebase requiring human review. [00:05:30](https://www.youtube.com/watch?v=tMHyp1_n8wY&t=330)
- The presenter concludes that while impressive, this is a routine application of AI to formal verification, not a fundamental breakthrough, and criticizes the academic hype. [00:21:03](https://www.youtube.com/watch?v=tMHyp1_n8wY&t=1263)
