# People are verifying the Riemann Hypothesis proof using spare CPU cycles

## Executive Summary

The video discusses the 'Riemann at Home' project, which invites volunteers to use spare CPU cycles to independently verify the AI-generated Lean proof of the Riemann hypothesis. The host highlights the playful, collaborative nature of the project, which replaces traditional software downloads with prompts for AI agents. He emphasizes the importance of independent verification for building trust in the proof, and reflects on how this marks a new era of collaborative mathematics. The video also critiques common oversimplifications of the Riemann hypothesis and celebrates the accessibility of modern mathematical verification.

## Key Points

- The 'Riemann at Home' project lets anyone use spare CPU cycles to verify the Lean proof of the Riemann hypothesis, similar to the old SETI@home project. [00:00:00](https://www.youtube.com/watch?v=MOo__X_3iMY&t=0)
- Instead of downloading software, participants use a plain-English prompt to instruct an AI agent to set up and run the verification, showcasing a shift in how software is distributed. [00:05:18](https://www.youtube.com/watch?v=MOo__X_3iMY&t=318)
- The host critiques the common simplification that the Riemann hypothesis is about prime numbers, clarifying it is about the zeros of a specific function. [00:09:29](https://www.youtube.com/watch?v=MOo__X_3iMY&t=569)
