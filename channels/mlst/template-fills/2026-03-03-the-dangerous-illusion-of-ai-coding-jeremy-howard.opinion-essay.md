## Thesis

AI coding tools like Claude Code create an illusion of control and productivity, but they degrade human skills and organizational knowledge, and they are fundamentally poor at software engineering.

## Argument

The core problem is that AI coding tools are evaluated on their ability to generate code, not on their ability to do software engineering. Software engineering is a discipline that requires deep intuition, understanding, and interaction with the system being built. LLMs, by contrast, are stochastic parrots that interpolate between training data. They can produce code that looks plausible, but they lack the ability to reason about the system as a whole, to anticipate edge cases, or to design novel solutions. This is why they fail at tasks that require going beyond the training distribution, like fixing the ipython kernel or designing a new architecture. The result is that organizations accumulate code that no one understands, and the people who use these tools become less competent over time, not more. The solution is not to abandon AI, but to build rich, interactive environments like notebooks that foster understanding and collaboration between humans and AI, and to focus on the human skills of design, engineering, and coding that are more important than ever.

## Counterpoints

- Some argue that AI coding tools make developers more productive, citing Anthropic's internal studies showing that their engineers are more productive with Claude Code.
- Others claim that AI can be creative, pointing to examples like Claude writing a C compiler in Rust, which they call 'clean room' implementation.
- A common objection is that AI can handle complex tasks like fixing the ipython kernel, which Jeremy himself experienced with Codex and GPT-5.3 Pro.
- There's a view that software development is becoming more important, not less, and that AI can help us build more powerful software by finding the right components.
- Some believe that the risks of AI are overblown, and that we should focus on the benefits, like enabling newbies to create apps and helping experts with routine work.
