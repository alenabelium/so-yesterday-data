## Thesis

AI coding tools like Claude Code create an illusion of control and productivity, but they degrade human skills and organizational knowledge, and true software engineering remains beyond their reach.

## Argument

The core problem is that AI coding tools are designed for code generation, not software engineering. Software engineering requires deep intuition, interaction with the system, and the ability to design and integrate components—skills that LLMs lack. As Jeremy Howard puts it, "They really bad at engineering software software. And I I think that's probably it. , will always be true." This is because LLMs operate by interpolating within their training data, not by understanding the underlying systems. They can produce code that looks plausible but often fails when pushed beyond familiar patterns. The illusion of control comes from the slot-machine-like interaction: you tweak prompts, configure MCPs, and pull the lever, but the output is stochastic and often incomprehensible. This leads to a "fatal loss of control" as AI-generated code accumulates, and no one understands the system. The result is that organizations lose the ability to maintain and evolve their software, and individuals lose the opportunity to develop their own skills. The solution is to create rich, interactive environments like notebooks where humans and AI can collaborate, with feedback loops that foster understanding and growth.

## Counterpoints

- Some argue that AI coding tools make individuals 50 times more productive, but this is only true for experts who already have deep domain knowledge and can guide the AI effectively.
- There is a claim that AI can solve complex problems like the IPython kernel issue, but this required extensive human oversight and left the code in a state that no one fully understands.
- The optimistic view of functionalism suggests that if the software works, it doesn't matter if we understand it, but this ignores the long-term risks of unmaintainable code and knowledge loss.
- Some believe that AI will lead to mass unemployment, but this ignores the fact that most software engineering work is not coding but understanding and designing systems, which AI cannot do.
