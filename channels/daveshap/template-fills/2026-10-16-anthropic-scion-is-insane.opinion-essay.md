## Thesis

Anthropic's Scion shows that the real bottleneck in agentic coding is human-centric infrastructure, and companies must rebuild tools for machines to unlock the productivity J-curve.

## Argument

The bottleneck isn't writing code anymore—it's the infrastructure built for human scale. Anthropic's merge rate jumped from 2,500 to over 30,000 per day in four months, and Git, designed for humans, couldn't keep up. So they built Scion, a server-centric system where agents fetch only what they need. The result: 200x less infrastructure, checkouts in seconds, and a seven-person team migrated the entire monorepo in five months—with Claude's help. Their job shifted from writing code to understanding systems and telling Claude no. Code review changed too: reviewers check intent, not every line, and merges happen concurrently, with Claude fixing conflicts faster than humans can spot them. This is the productivity J-curve in action. Companies that just give engineers agents but keep human-centric tools will see gains lost—they've moved the bottleneck from typing to reading. The real win comes from asking what source control would look like if built for machines first. That's how post-labor arrives: not as mass layoffs, but as compaction—output grows, headcount stays flat. Anthropic expects others to hit these limits in 6-12 months. The lesson: don't pave the cow paths. Find every process built around human speed and rebuild it for machines. That's where the next 10-fold gain lives.

## Counterpoints

- Some might argue that giving every engineer an AI agent is enough, but if code still flows through human-centric tools, the bottleneck just moves from typing to reading.
- Solo's paradox suggests technology adoption doesn't immediately show up in productivity stats—companies must reorganize around the new tech first, which can cause a dip before the J-curve shoots up.
- One might think that human labor remains essential, but Anthropic's engineers say their work is changing, not disappearing—they're no less valuable, but they're no longer the binding constraint.
