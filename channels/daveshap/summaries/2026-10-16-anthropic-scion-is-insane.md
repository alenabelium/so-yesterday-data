# Anthropic Scion is INSANE

## Executive Summary

Anthropic's new source control system, Scion, was built to handle the massive increase in code merges driven by AI agents, growing from 2,500 to over 30,000 merges per day. The system, built by a team of seven with Claude's help, runs on 200 times less infrastructure and represents a shift from human-centric tools like Git to machine-first design. This example illustrates the productivity J-curve and the concept of post-labor economics, where human labor is no longer the binding constraint on output. The video argues that companies must rethink workflows built for human scale to unlock the full benefits of agentic coding.

## Key Points

- Anthropic's code merges grew from 2,500 to over 30,000 per day, driven by Claude, and Git became the bottleneck, leading to the creation of Scion, a server-centric version control system. [00:01:25](https://www.youtube.com/watch?v=3199TC7Pt_o&t=85)
- Scion, built by a team of seven with Claude's help, runs on 200 times less infrastructure and makes checkouts take seconds instead of minutes, demonstrating the productivity J-curve in action. [00:04:02](https://www.youtube.com/watch?v=3199TC7Pt_o&t=242)
- The video argues that companies must stop 'paving cow paths' and redesign workflows for machines first, as human-centric tools like Git limit the gains from agentic coding. [00:05:04](https://www.youtube.com/watch?v=3199TC7Pt_o&t=304)
- Post-labor economics arrives through compaction—output grows while headcount stays flat—and the remaining human value lies in accountability, long-term goals, relationships, and undocumented knowhow. [00:07:30](https://www.youtube.com/watch?v=3199TC7Pt_o&t=450)
