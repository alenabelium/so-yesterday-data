## Wider context

The week's theme is the agent-centric paradigm shift: Microsoft and Google both reposition agents as the core, with apps as tools. This is reinforced by agentic coding workflows that beat humans, agent memory and self-improvement, and the rise of agentic token usage outpacing human tokens 14x. The trend points to agents becoming the primary interface for work, with implications for software architecture and user interaction.
