## Headline takeaway

Install the new ChatGPT desktop app to master Work for automation, Codex for coding, and remote mobile control.

## Prerequisites

### ChatGPT Account
- **Kind**: account
- **Note**: Required to sign in and access Work/Codex modes.

### Paid Plan
- **Kind**: account
- **Note**: Upgrade needed for advanced features like unlimited image generation.

### Windows/Mac/OS
- **Kind**: os
- **Note**: Download the installer for your specific operating system.

## Steps

### Download and Install App
- **Timestamp**: [00:00](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=0)
- **Action**: Navigate to the official webpage, download the installer for your OS, and run the setup wizard.
- **Command Or Clicks**: Click download button -> Open installer -> Follow setup instructions
- **Choice Branch**: Select Windows, Mac, or Linux installer based on your system.

### Sign In and Configure Sidebar
- **Timestamp**: [00:30](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=30)
- **Action**: Authenticate your account upon first launch. Use the top-left button to show or hide the sidebar.
- **Command Or Clicks**: Click 'Continue' to authenticate -> Click top-left button to toggle sidebar
- **Choice Branch**: None

### Switch to Work Mode and Set Workspace
- **Timestamp**: [01:12](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=72)
- **Action**: Select 'Work' from the sidebar dropdown for productivity tasks. Create a new task and assign a local folder for file I/O.
- **Command Or Clicks**: Click 'Work' dropdown -> Click 'New Task' -> Select folder -> Click 'Save'
- **Choice Branch**: Choose 'Codex' for software development instead.

### Manage Plugins
- **Timestamp**: [02:49](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=169)
- **Action**: Browse and install plugins (e.g., Notion) via the plugin menu. Authenticate with third-party services as prompted.
- **Command Or Clicks**: Click 'Plugins' -> 'Connect Plugins' -> 'Browse all' -> Click plugin -> 'Install'
- **Choice Branch**: Click three dots on a plugin to uninstall it.

### Configure Approval Mode
- **Timestamp**: [03:54](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=234)
- **Action**: Set approval mode to 'Approve for me' (default) or 'Full access' (autopilot). Full access triggers a warning.
- **Command Or Clicks**: Click approval mode dropdown -> Select 'Approve for me' or 'Full access'
- **Choice Branch**: Select 'Full access' only if you trust the agent for long-running tasks.

### Enable Remote Mobile Control
- **Timestamp**: [05:00](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=300)
- **Action**: Go to Settings > Connections > Control this PC. Scan the QR code with the ChatGPT mobile app to sync.
- **Command Or Clicks**: Settings -> Connections -> Control this PC -> Add -> Scan QR code
- **Choice Branch**: None

### Select Model and Effort Level
- **Timestamp**: [05:00](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=300)
- **Action**: Click the model dropdown, select 'Advanced', and choose Sol (flagship), Terra (mid), or Luna (cheap/fast). Set effort to High.
- **Command Or Clicks**: Click model dropdown -> Advanced -> Select Sol/Terra/Luna -> Set effort to High
- **Choice Branch**: Use Luna for cheap tasks, Sol for complex ones.

### Run Work Task and View Output
- **Timestamp**: [06:01](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=361)
- **Action**: Send a prompt to create a file (e.g., Excel). Monitor progress on your phone. Open the generated file in its default app.
- **Command Or Clicks**: Type prompt -> Send -> Open file via top-right button -> Select Excel
- **Choice Branch**: Use voice dictation for faster prompting.

### Deploy Website via TryGPT
- **Timestamp**: [08:05](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=485)
- **Action**: Ask the agent to create a visual web page. TryGPT will deploy it. Share the link by changing visibility to 'Anyone on the internet'.
- **Command Or Clicks**: Prompt: 'Create web page' -> Click link -> Click 'Share' -> Change to 'Anyone'
- **Choice Branch**: None

### Set Up Scheduled Tasks
- **Timestamp**: [13:04](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=784)
- **Action**: Go to Scheduled, create a new task manually. Set prompt, project, model, frequency (e.g., daily 9 AM), and title.
- **Command Or Clicks**: Scheduled -> Create -> Set up manually -> Set frequency -> Create
- **Choice Branch**: Run manually anytime via the three-dot menu.

### Use Computer Use Plugin
- **Timestamp**: [15:45](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=945)
- **Action**: Ensure Computer Use plugin is installed. Ask the agent to control your PC (e.g., open Word). Watch for the blue outline indicating control.
- **Command Or Clicks**: Prompt: 'Use computer use to open Word'
- **Choice Branch**: None

### Switch to Codex Mode
- **Timestamp**: [16:57](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=1017)
- **Action**: Switch dropdown to Codex for coding. The agent will use Git, version control, and standard dev workflows.
- **Command Or Clicks**: Click 'Codex' dropdown
- **Choice Branch**: None

## Gotchas

- **Severity**: serious
- **Timestamp**: [03:54](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=234)

### Fast speed nearly doubles your usage. Stick to standard speed to manage costs.
- **Severity**: serious
- **Timestamp**: [06:01](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=361)

### Advanced features require a paid plan upgrade. Check usage remaining in your profile.
- **Severity**: blocking
- **Timestamp**: [06:01](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=361)
