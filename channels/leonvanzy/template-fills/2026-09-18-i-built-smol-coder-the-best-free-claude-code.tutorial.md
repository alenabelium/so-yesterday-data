## Headline takeaway

Build complex local AI projects for free using Smol Coder's optimized planning system.

## Prerequisites

### Ollama or LM Studio
- **Kind**: tool
- **Note**: Required to download and run local open-weight models like Qwen 2.5.

### Node.js Environment
- **Kind**: tool
- **Note**: Needed to run the npm install command for Smol Coder.

### 16GB+ VRAM/Unified Memory
- **Kind**: hardware
- **Note**: Recommended for running Qwen 2.5 (approx 18GB model size).

## Steps

### Install Smol Coder globally
- **Timestamp**: [01:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=90)
- **Action**: Open a terminal or PowerShell and install the tool via npm.
- **Command Or Clicks**: npm install -g smol-coder@latest

### Download Qwen 2.5 model
- **Timestamp**: [03:51](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=231)
- **Action**: Install Ollama, then download the Qwen 2.5 coding model.
- **Command Or Clicks**: ollama pull qwen2.5

### Verify model functionality
- **Timestamp**: [03:15](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=195)
- **Action**: Test the model locally to ensure it loads and responds.
- **Command Or Clicks**: ollama run qwen2.5

### Launch Smol Coder in terminal
- **Timestamp**: [04:10](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=250)
- **Action**: Navigate to your project folder and start the CLI interface.
- **Command Or Clicks**: smol

### Configure model and effort
- **Timestamp**: [04:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=270)
- **Action**: Select the local model and set reasoning effort within the CLI.
- **Command Or Clicks**: /models [Enter] then /effort high [Enter]

### Switch to Web UI
- **Timestamp**: [05:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=330)
- **Action**: Start the web-based interface for a visual project sidebar.
- **Command Or Clicks**: smol-web

### Build Tic-Tac-Toe game
- **Timestamp**: [08:45](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=525)
- **Action**: Send a prompt to create a browser-based multiplayer game.
- **Command Or Clicks**: create a tic-tac-toe multiplayer game that runs in a browser

### Run the dev server
- **Timestamp**: [09:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=570)
- **Action**: Ask the agent to start the development server for the new project.
- **Command Or Clicks**: please start the dev server

### Build Minecraft clone via spec
- **Timestamp**: [11:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=690)
- **Action**: Paste a detailed spec generated by an external LLM into Smol Coder.
- **Command Or Clicks**: [Paste full HTML/CSS/JS spec prompt]

### Fix rendering bugs via vision
- **Timestamp**: [12:45](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=765)
- **Action**: Attach a screenshot of missing textures to the agent for correction.
- **Command Or Clicks**: [Paste screenshot] it seems like there are textures missing right there

## Gotchas

### Context windows on free models are small; frequent compaction occurs, so the planning system is critical to keep the agent on track.
- **Severity**: serious
- **Timestamp**: [08:45](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=525)

### Ensure your model supports vision tool calling if you plan to attach screenshots for debugging.
- **Severity**: heads_up
- **Timestamp**: [13:06](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=786)
