## Headline takeaway

Build a terminal-style portfolio with streaming animations and deploy it automatically via GitHub and Hostinger.

## Prerequisites

### GitHub Account
- **Kind**: account
- **Note**: Required to host the project repository and enable continuous integration for automatic deployments.

### Hostinger Account
- **Kind**: account
- **Note**: Hosting provider used for deploying the Node.js web app and managing the domain.

### Node.js Environment
- **Kind**: tool
- **Note**: Required to run npx create-next-app and manage the Next.js project dependencies.

## Steps

### Initialize Next.js project
- **Timestamp**: [00:00](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=0)
- **Action**: Open a blank folder and run the command to download and install Next.js.
- **Command Or Clicks**: NPX create-next-app @latest .

### Install Next Best Practices skill
- **Timestamp**: [00:00](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=0)
- **Action**: Copy the skill installation command, paste it into the terminal, select Cloud Code, press enter, and install the project table.
- **Command Or Clicks**: Paste skill command -> Select Cloud Code -> Press Enter -> Install project table

### Install front-end design skill
- **Timestamp**: [00:00](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=0)
- **Action**: Install the front-end design skill to improve the UI experience.
- **Command Or Clicks**: Install front-end design skill

### Switch to planning mode and paste prompt
- **Timestamp**: [01:31](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=91)
- **Action**: Switch the coding agent to planning mode and paste the research and build prompt to instruct the agent to create a terminal-style page.
- **Command Or Clicks**: Switch to planning mode -> Paste research and build prompt

### Approve implementation plan
- **Timestamp**: [02:25](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=145)
- **Action**: Approve the implementation plan generated by the agent to start building the UI.
- **Command Or Clicks**: Approve implementation plan

### Add streaming animations prompt
- **Timestamp**: [02:25](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=145)
- **Action**: Paste the second prompt from the prompts folder to add typing animations and simulate tool calls.
- **Command Or Clicks**: Paste animation prompt

### Implement Q&A chat window
- **Timestamp**: [04:32](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=272)
- **Action**: Create a QA.json file with questions and answers, then use regex to match user input to answers, simulating a chatbot.
- **Command Or Clicks**: Create QA.json -> Paste Q&A prompt

### Commit and publish to GitHub
- **Timestamp**: [05:39](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=339)
- **Action**: Create a commit named 'final', publish the branch, and name the repository 'portfolio website tutorial'.
- **Command Or Clicks**: git commit -m 'final' -> Publish branch -> Name repo 'portfolio website tutorial'

### Deploy to Hostinger via GitHub
- **Timestamp**: [05:39](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=339)
- **Action**: In Hostinger, select 'migrate an existing site', choose 'deploy your Node.js web app', and connect the GitHub repository.
- **Command Or Clicks**: Hostinger -> Migrate existing site -> Deploy Node.js app -> Connect GitHub repo

### Verify automatic deployment
- **Timestamp**: [08:18](https://www.youtube.com/watch?v=DwvZ9f0RYzA&t=498)
- **Action**: Make a code change, push to GitHub, and verify that Hostinger automatically builds and deploys the update.
- **Command Or Clicks**: Push code change -> Check Hostinger deployment log
