# The Only PewDiePie Odysseus AI Tutorial You'll Need

## Executive Summary

This tutorial introduces Odysseus AI, a self-hosted workspace created by PewDiePie that prioritizes data privacy by allowing users to store all conversations and files on their own hardware. The video demonstrates how to set up the platform locally using Docker, Git, and local inference engines like Ollama and LM Studio, ensuring complete control over sensitive data. It further guides viewers through deploying the instance on a Virtual Private Server (VPS) via Hostinger to enable remote access and integration with paid API providers like OpenRouter. Key features highlighted include deep research capabilities, a 'second brain' memory system, and customizable agent skills.

## Key Points

- Odysseus AI is an open-source, self-hosted workspace that keeps all data private by running on user-owned hardware, avoiding reliance on third-party cloud providers for storage or inference.
- The setup process involves installing Docker Desktop and Git, cloning the GitHub repository, and configuring environment variables to launch the local instance and connect it to local models via Ollama or LM Studio.
- Advanced features include a 'deep research' agent for detailed reports, a 'second brain' for persistent memory storage, and the ability to integrate email accounts and custom GitHub skills for automated workflows.
- For remote access, the tutorial demonstrates deploying Odysseus on a Hostinger VPS using a one-click install, then connecting it to OpenRouter to access powerful cloud models like Claude and GPT without sacrificing the platform's flexibility.
