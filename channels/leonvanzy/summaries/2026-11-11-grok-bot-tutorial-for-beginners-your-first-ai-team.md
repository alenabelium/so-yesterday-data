# Grok Bot Tutorial for Beginners: Your First AI Team

## Executive Summary

Grok Bot is presented as a versatile AI platform that allows users to create and manage multiple autonomous agents capable of performing complex tasks, such as designing a house, without direct supervision. The tutorial demonstrates how to set up Grok Bot, create a team of specialized bots, and use features like shared context, scheduled routines, and integration with external services like GitHub and Vercel. The video highlights Grok Bot's ability to automatically select the best models and tools for tasks, its cloud-based operation, and its integration with X and Cursor subscriptions.

## Key Points

- Grok Bot allows users to create multiple AI agents that run on XAI infrastructure, enabling them to work independently even when the user's laptop is closed. [00:00:00](https://www.youtube.com/watch?v=7b6cMUBxUtw&t=0)
- Grok Bot automatically selects the best model and tools for each task, supporting a variety of models including competitors' models like Claude Opus 5.5 and Midjourney. [00:02:34](https://www.youtube.com/watch?v=7b6cMUBxUtw&t=154)
- Users can create teams of bots with shared context, delegate tasks, and even have bots create new bots and groups, as demonstrated by creating an architect and a 3D home designer. [00:10:27](https://www.youtube.com/watch?v=7b6cMUBxUtw&t=627)
- Grok Bot supports integrations with services like GitHub and Vercel, allowing agents to manage repositories and deploy web applications. [00:13:55](https://www.youtube.com/watch?v=7b6cMUBxUtw&t=835)
