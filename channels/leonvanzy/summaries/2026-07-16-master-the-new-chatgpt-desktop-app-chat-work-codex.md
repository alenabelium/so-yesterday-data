# Master the New ChatGPT Desktop App - Chat, Work & Codex

## Executive Summary

The video provides a comprehensive walkthrough of the new ChatGPT desktop app, which integrates ChatGPT, the Codex coding agent, and the Work agent into a single interface. It explains the distinct use cases for Work (productivity and automation) versus Codex (software development) and guides users through installation, plugin management, and model selection. The presenter demonstrates key capabilities including remote mobile control, scheduled tasks, web deployment, and direct computer control via the computer use plugin.

## Key Points

- The app merges ChatGPT, Codex, and Work, allowing users to switch between productivity tasks and coding workflows within one environment [00:01:12](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=72).
- Users can manage plugins, select from GPT-5.6 variants (Sol, Terra, Luna), and enable remote control of the agent via a mobile phone [00:03:54](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=234).
- Work mode supports creating Excel files, deploying visual websites via TryGPT, and setting up recurring scheduled tasks for automation [00:08:05](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=485).
- The desktop app features a floating chat bubble, persistent memory settings, and powerful computer use capabilities that allow the agent to control external applications like Word and browsers [00:15:45](https://www.youtube.com/watch?v=QUH3N1y1mYA&t=945).
