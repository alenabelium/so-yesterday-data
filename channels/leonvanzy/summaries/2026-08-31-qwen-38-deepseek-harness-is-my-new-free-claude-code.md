# Qwen 3.8 + DeepSeek Harness Is My New Free Claude Code

## Executive Summary

The video introduces DeepSeek Harness as a free, open-source, composable agent framework that serves as an alternative to paid coding assistants like Claude Code. It demonstrates how users can install the tool, connect various AI providers including local models via Ollama, and customize functionality through a plugin-based architecture. The presenter highlights the ability to create custom presets for specific use cases, such as optimizing performance for local LLMs by disabling unnecessary tools. Finally, the tutorial covers the process of building, testing, and distributing custom plugins to extend the harness's capabilities.

## Key Points

- DeepSeek Harness is a fully composable agent framework where every component, from UI to models, is driven by plugins, allowing for extensive customization and the ability to disable or add features as needed [00:01:22](https://www.youtube.com/watch?v=N7Hkqznvc7I&t=82).
- Users can integrate local models like Qwen 3.8 using Ollama by adding a custom provider in the settings, enabling free and private coding assistance without relying on cloud APIs [00:10:24](https://www.youtube.com/watch?v=N7Hkqznvc7I&t=624).
- The harness allows for the creation of agent presets to tailor tool access, such as removing sub-agent capabilities for local models to prevent context window bloat and improve efficiency [00:09:29](https://www.youtube.com/watch?v=N7Hkqznvc7I&t=569).
- Developers can build, test in memory, and make permanent custom plugins using the agent itself, then distribute them via standard installation commands for community sharing [00:14:29](https://www.youtube.com/watch?v=N7Hkqznvc7I&t=869).
