# I Built Smol Coder, the Best Free Claude Code

## Executive Summary

Leon van Zyl introduces Smol Coder, an open-source tool designed to optimize free local large language models for coding tasks, addressing the context window limitations of existing harnesses like Claude Code. The video provides a step-by-step tutorial on installing Smol Coder and setting up local models via Ollama or LM Studio. It demonstrates how Smol Coder's unique planning system keeps agents focused during frequent context compaction, enabling the successful creation of complex projects like a Minecraft clone without API costs.

## Key Points

- Smol Coder solves the issue of small context windows in free local models by optimizing system prompts and introducing a persistent to-do list that helps the agent stay on track after compaction [00:02:30](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=150).
- The installation process involves using npm to install Smol Coder globally and downloading a model like Qwen 2.5 via Ollama, with automatic detection of local models in both terminal and web-based interfaces [00:03:15](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=195).
- For complex projects, the recommended workflow is to use a larger AI model to generate a detailed specification, which is then fed into Smol Coder to implement the code uninterrupted for extended periods [00:11:45](https://www.youtube.com/watch?v=u2vaM7ppzuE&t=705).
