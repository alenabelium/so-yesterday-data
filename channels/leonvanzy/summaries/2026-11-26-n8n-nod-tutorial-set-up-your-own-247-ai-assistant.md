# n8n Nod Tutorial: Set Up Your Own 24/7 AI Assistant

## Executive Summary

This tutorial introduces Node, an open-source AI assistant from the n8n team, designed to run 24/7 on your own server. It positions Node as a middle ground between polished but closed commercial agents and powerful but technical open-source alternatives. The video demonstrates deploying Node on a Hostinger VPS, connecting it to email, calendar, Telegram, and n8n workflows, and highlights its security features, including prompt injection resistance. By the end, viewers learn how to set up a personal AI assistant that can manage tasks, schedules, and integrations with minimal technical effort.

## Key Points

- Node is an open-source AI assistant from the n8n team that runs on your own server, giving you control over your data and AI model choice, and is easier to set up than alternatives like Hermes Agent. [00:02:10](https://www.youtube.com/watch?v=vy_NCzx_hAE&t=130)
- Deploy Node on a VPS (e.g., Hostinger KVM 4) to ensure it runs 24/7, and connect it to messengers like Telegram and WhatsApp for remote access. [00:04:52](https://www.youtube.com/watch?v=vy_NCzx_hAE&t=292)
- Node includes security features like encrypted password storage, permission checks before actions, and resistance to prompt injection attacks, as demonstrated in the video. [00:13:03](https://www.youtube.com/watch?v=vy_NCzx_hAE&t=783)
- Integrate Node with n8n via MCP to manage and run workflows directly from your assistant, enabling automation like triggering a daily AI briefing. [00:15:54](https://www.youtube.com/watch?v=vy_NCzx_hAE&t=954)
