# I Built a Free 3D Software Factory Run by Claude Code Agents

## Executive Summary

Leon van Zyl demonstrates Cube Forge, an open-source 3D software factory where Claude Code and Codex agents autonomously manage GitHub issues and pull requests. The video highlights new features like agent idle activities, a CEO agent that auto-scales teams, and cloud execution via Upstash Boxes, which allows agents to run even when the user's PC is off. The project offers a gamified interface with rewards, voice interactions, and a mission control dashboard, making agent orchestration more interactive and scalable.

## Key Points

- Cube Forge is a free, open-source 3D software factory where each agent is a Claude Code or Codex instance, working on real GitHub issues and pull requests. [00:00:00](https://www.youtube.com/watch?v=NAQyKMdxRT4&t=0)
- The CEO agent now treats all agents as universal, automatically scaling the team based on project needs, and can be interacted with via voice or text. [00:03:07](https://www.youtube.com/watch?v=NAQyKMdxRT4&t=187)
- Agents can now run in the cloud using Upstash Boxes, each on a separate virtual machine, allowing them to continue working even when your PC is off. [00:10:10](https://www.youtube.com/watch?v=NAQyKMdxRT4&t=610)
