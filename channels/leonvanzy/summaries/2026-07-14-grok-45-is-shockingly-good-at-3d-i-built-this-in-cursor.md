# Grok 4.5 is Shockingly Good at 3D - I Built This in Cursor

## Executive Summary

This video demonstrates how to build and deploy a 3D-enabled website using Grok 4.5 within the Cursor IDE, highlighting the model's cost efficiency and speed compared to other flagship AI models. The presenter walks through setting up a project in planning mode to avoid context window limitations, utilizing Cursor's integrated image generation for assets, and iterating on the 3D scene via natural language prompts. Finally, the tutorial covers configuring Hostinger's API via MCP to enable one-click deployment of the finished application directly from the IDE.
