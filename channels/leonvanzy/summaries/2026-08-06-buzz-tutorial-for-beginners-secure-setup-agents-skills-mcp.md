# Buzz Tutorial for Beginners: SECURE Setup, Agents, Skills & MCP

## Executive Summary

This video provides a comprehensive tutorial on setting up Buzz, an open-source, Slack-like interface for managing multiple AI agents. The presenter demonstrates how to securely self-host Buzz on a VPS to maintain data privacy while connecting various AI providers including Claude, OpenAI, Kimi, and local open-source models. Key features highlighted include the ability to create specialized agents with distinct roles, integrate external skills and MCP servers, and control the agent team via a mobile device. The tutorial concludes by showcasing a multi-agent workflow where agents collaborate to complete complex tasks like generating a team slide deck.

## Key Points

- Buzz allows users to self-host a secure, Slack-style interface for managing AI agents, supporting diverse providers like Claude, OpenAI, and local models via Open Code. [00:03:24](https://www.youtube.com/watch?v=xJEFjE88wdw&t=204)
- Users can customize agents by assigning specific harnesses (e.g., Claude Code, CodeEx) and models, and extend capabilities by installing skills and MCP servers through CLI tools. [00:07:45](https://www.youtube.com/watch?v=xJEFjE88wdw&t=465)
