# Should You Still Learn to Code? 20 Years of Dev Advice

## Executive Summary

Leon van Zyl, a software developer with 20 years of experience, argues that while AI agents will significantly reduce the amount of code developers write, the ability to read and understand code remains a core skill. He emphasizes that developers must take responsibility for agent-generated code, ensuring its security and scalability. He provides practical advice on using AI assistants as learning tools, building a personal knowledge arsenal, and implementing professional workflows like memory files and GitHub-based task management. He concludes by urging developers to embrace agents gradually, focusing on prevention rather than avoidance, as coding agents are the future.

## Key Points

- The reality of software development is that you will write significantly less code, but being able to read code is a core skill; review all agent changes and fix simple issues yourself. [00:01:09](https://www.youtube.com/watch?v=XtvbzN67PhA&t=69)
- Use your AI assistant as a patient teacher by exploring open-source projects on GitHub, asking it to explain the technology stack and specific features, and then writing down what you learn to build your own toolkit. [00:07:39](https://www.youtube.com/watch?v=XtvbzN67PhA&t=459)
- Master memory files (like CLAUDE.md or AGENTS.md) to set project rules and preferences, and use GitHub issues and pull requests to manage agent tasks, ensuring tests, linting, and type checks pass before merging. [00:14:46](https://www.youtube.com/watch?v=XtvbzN67PhA&t=886)
- Conduct regular security audits using skills like 'app review' that reference OWASP Top 10, and create GitHub tickets for any vulnerabilities found, then have agents fix them and provide evidence in pull requests. [00:18:23](https://www.youtube.com/watch?v=XtvbzN67PhA&t=1103)
- For skeptical developers, focus on prevention rather than avoidance: start with low-risk tasks like updating tests or documentation, and gradually integrate agents into your workflow. [00:20:30](https://www.youtube.com/watch?v=XtvbzN67PhA&t=1230)
