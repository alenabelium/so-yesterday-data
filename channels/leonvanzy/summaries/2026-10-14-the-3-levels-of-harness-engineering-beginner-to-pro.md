# The 3 Levels of Harness Engineering (Beginner to Pro)

## Executive Summary

The video explains that most developers only use the first level of harness engineering—configuration—when working with AI coding tools like Claude Code. The author argues that to truly excel as an AI engineer, one must progress to creating custom tools and eventually orchestration harnesses that manage multiple agents. He provides examples and evidence that custom tools can significantly improve model performance, and he showcases advanced orchestration systems like AutoForge and a 3D software factory. The video emphasizes that understanding and mastering these three levels is crucial for building a career in AI engineering.

## Key Points

- The first level of harness engineering is configuration, where you use vendor-provided tools like Claude Code and customize them via memory files (e.g., agents.md) and hooks to enforce rules and behaviors. [00:04:10](https://www.youtube.com/watch?v=z1EaBe9oIME&t=250)
- The second level involves building your own custom tools, which can dramatically improve model performance—for example, LangChain improved GPT-5.2 results from 53% to 66% by changing the toolkit, and Ken Bullock boosted Grok Code Fast One's score from 6.7% to nearly 70%. [00:08:55](https://www.youtube.com/watch?v=z1EaBe9oIME&t=535)
- The third level is orchestration harnesses, which control multiple coding agents simultaneously, enabling long-running tasks and swarms of agents that work autonomously on hundreds of features, as demonstrated by AutoForge and a 3D software factory. [00:13:22](https://www.youtube.com/watch?v=z1EaBe9oIME&t=802)
