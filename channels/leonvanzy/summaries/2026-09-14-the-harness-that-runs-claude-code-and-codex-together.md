# The Harness That Runs Claude Code and Codex Together

## Executive Summary

Omnigen is an open-source harness created by Databricks co-founder Matei Zaharia that unifies multiple AI coding agents, such as Claude Code and Codex, into a single system. It addresses the friction of managing disparate tools by allowing users to share context, history, and security policies across different providers. The platform introduces critical safety features like 'policies' to prevent data exfiltration via the 'lethal trifecta' of agent capabilities. Additionally, it streamlines complex workflows through built-in agents like Polly for task distribution and Debbie for multi-agent debate and consolidation.

## Key Points

- Omnigen simplifies managing multiple coding agents by providing a unified interface where users can switch between providers like Claude Code and Codex without losing context or switching terminals [00:01:10](https://www.youtube.com/watch?v=gYtQ1LKSgXY&t=70).
- The platform implements 'policies' to mitigate the 'lethal trifecta' risk, blocking agents from combining reading private data, accessing external sources, and sending data out simultaneously [00:04:10](https://www.youtube.com/watch?v=gYtQ1LKSgXY&t=250).
- Built-in agents like Debbie enable multi-agent debates where different models review and improve plans, while Polly orchestrates the distribution of implementation tasks across specialized sub-agents [00:08:46](https://www.youtube.com/watch?v=gYtQ1LKSgXY&t=526).
- The system supports seamless workflow integration by forking conversations between planning and implementation phases, allowing users to leverage the strengths of different models for each stage [00:11:35](https://www.youtube.com/watch?v=gYtQ1LKSgXY&t=695).
