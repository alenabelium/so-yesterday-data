# OpenAI Dots: Set Up Your Own Always-On AI Assistant

## Executive Summary

OpenAI Dots is a new feature from OpenAI that allows users to create persistent, always-on AI assistants within the ChatGPT ecosystem, running on GPT-6 Astra and capable of proactive research, task execution, and scheduled tasks. Unlike open-source alternatives like OpenClaw or Hermes Agent, Dots require no self-hosting or VPS, as everything is included in a ChatGPT Pro subscription. The video demonstrates setting up a Dot, connecting it to apps, giving it access to a virtual computer, and using features like calling, reminders, and Spaces for collaborative work. The presenter highlights the unique value of Dots' dedicated computer and browser, which enable advanced tasks like 3D modeling in Blender.

## Key Points

- OpenAI Dots are permanent agents that run in the ChatGPT ecosystem, even when your computer is off, and use GPT-6 Astra with a standout memory system. [00:00:00](https://www.youtube.com/watch?v=niv2BEcOkR8&t=0)
- Dots can connect to over 4,000 apps, have their own browser and computer, and can be interacted with via the ChatGPT app, Slack, and Microsoft Teams. [00:00:47](https://www.youtube.com/watch?v=niv2BEcOkR8&t=47)
- The three main uses for Dots are proactive research, task execution, and scheduled tasks, with safety fences to control what the agent can do. [00:01:42](https://www.youtube.com/watch?v=niv2BEcOkR8&t=102)
- Dots are available on the Pro plan ($100/month) and can be set up via the ChatGPT desktop app, with the ability to pause, reboot, or remove the agent. [00:02:32](https://www.youtube.com/watch?v=niv2BEcOkR8&t=152)
- The agent's dedicated computer can be viewed and controlled, allowing tasks like creating 3D models in Blender, and Spaces can be used for collaborative research and idea generation. [00:08:16](https://www.youtube.com/watch?v=niv2BEcOkR8&t=496)
