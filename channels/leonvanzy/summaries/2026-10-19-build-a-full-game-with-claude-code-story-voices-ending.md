# Build a Full Game with Claude Code (Story, Voices, Ending)

## Executive Summary

Leon van Zyl demonstrates a 10-step workflow for creating a complete game using Claude Code, from plot development and art style selection to voice acting, music, and deployment. The video emphasizes that non-developers can replicate the process, using a cozy horror game as an example, and includes a free agent skill for automation. Key steps include creating debugging tools, generating art mockups, integrating audio via 11 Labs, building a vertical slice with critic agents, and deploying the final game online using Hostinger.

## Key Points

- The workflow starts with defining the plot, characters, and locations in detail, and Claude saves this information in the project's docs folder for future sessions. [00:02:40](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=160)
- Claude creates its own debugging tools to test specific scenes and ensure objects are aligned, avoiding issues like floating items. [00:04:32](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=272)
- The art style is chosen from multiple mockups, and Claude turns the selected style into a rulebook for consistent visuals. [00:05:24](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=324)
- Audio assets (voiceover, music, sound effects) are generated using 11 Labs, with options for local alternatives, and Claude creates a page to review and adjust voices. [00:07:15](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=435)
- A vertical slice of the game is built and reviewed by three critic agents (harsh critic, horror director, narrative agent) to refine gameplay and scares. [00:10:22](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=622)
- The final game is deployed online using Hostinger and the Inworld connector, making it playable by anyone with the link. [00:13:45](https://www.youtube.com/watch?v=HaEZgh2RadQ&t=825)
