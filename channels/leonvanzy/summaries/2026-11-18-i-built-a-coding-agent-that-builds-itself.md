# I Built a Coding Agent That Builds Itself

## Executive Summary

Leon van Zyl introduces Code Den, an open-source, MIT-licensed tool that implements four levels of AI coding systems, from individual agent sessions to a fully autonomous 'dark factory' that detects issues, assigns tasks to a swarm of agents, and merges changes without human intervention. The video demonstrates how Code Den's orchestrator and project managers streamline multi-project management, and how its software factory mode uses GitHub issues and merge requests to automate development workflows. The dark factory mode removes the user from the loop entirely, with a scout agent identifying improvements and automatically implementing them after passing tests, verification, and security audits.

## Key Points

- Code Den supports four levels of AI coding: individual agent sessions, multi-agent orchestration, software factory with GitHub-based task management, and a fully autonomous dark factory that merges changes without human approval. [00:00:00](https://www.youtube.com/watch?v=etrC9bplAbA&t=0)
- Automations in Code Den allow scheduled or event-triggered agent runs, such as hourly security scans, with results sent to project managers or new sessions. [00:07:38](https://www.youtube.com/watch?v=etrC9bplAbA&t=458)
- The software factory mode uses a vision file, trusted authors, daily budgets, and a swarm of agents to process GitHub issues, with changes verified by a different provider before merging. [00:14:33](https://www.youtube.com/watch?v=etrC9bplAbA&t=873)
- Dark factory mode removes the user from the loop: a scout agent analyzes the codebase, creates tasks, and the factory automatically merges changes after passing checks and reviews. [00:23:07](https://www.youtube.com/watch?v=etrC9bplAbA&t=1387)
