# From Vibe Coder to AI Engineer: The Complete Roadmap

## Executive Summary

Leon van Zyl presents a roadmap for transitioning from a 'vibe coder' to an 'AI engineer' mindset, emphasizing the importance of understanding the underlying technology stack and taking responsibility for applications built with AI agents. He outlines a step-by-step workflow that includes learning from coding agents, building a skills repository, using memory files, implementing team workflows with GitHub issues and branches, and leveraging CI/CD pipelines for automated testing. The talk progresses to advanced topics like running multiple agents in parallel, proactive monitoring, and creating custom coding environments, culminating in the concept of a 'software factory' where agents autonomously handle tasks. Throughout, he stresses the need for security audits, code reviews, and continuous learning to build robust, production-ready applications.

## Key Points

- The AI engineer role requires understanding the technology stack and taking responsibility for the code, unlike a vibe coder who relies solely on agents. [00:02:28](https://www.youtube.com/watch?v=uD99aKV4fq8&t=148)
- Use your coding agent as a teacher: ask it to explain how a project works, take notes on the tech stack, and recreate similar apps to build experience. [00:05:59](https://www.youtube.com/watch?v=uD99aKV4fq8&t=359)
- Create your own agent skills instead of copying others; build a personal skills repository on GitHub and use memory files to enforce consistent rules. [00:12:44](https://www.youtube.com/watch?v=uD99aKV4fq8&t=764)
- Adopt a team workflow using GitHub issues, branches, and working trees to manage changes, and integrate CI/CD pipelines with automated tests to catch regressions. [00:16:20](https://www.youtube.com/watch?v=uD99aKV4fq8&t=980)
- Scale to a 'software factory' where multiple agents work in parallel, proactively monitor for issues, and create pull requests, all managed through GitHub. [00:29:49](https://www.youtube.com/watch?v=uD99aKV4fq8&t=1789)
