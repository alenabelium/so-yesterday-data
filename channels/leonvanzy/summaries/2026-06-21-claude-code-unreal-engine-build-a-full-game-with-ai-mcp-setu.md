# Claude Code + Unreal Engine: Build a Full Game with AI (MCP Setup Tutorial)

## Executive Summary

This video demonstrates how non-developers can build complex game prototypes using Claude Code and Unreal Engine's Model Context Protocol (MCP). The creator guides viewers through the initial setup of the MCP server, enabling necessary plugins, and configuring the coding agent to interact with the engine. By leveraging AI for research, asset management, and implementation, the tutorial shows how to create a functional 'GTA-style' vertical slice in a fraction of the traditional time. The process highlights the potential of agentic coding to accelerate indie game development while noting current limitations in parallel processing.

## Key Points

- Setting up the environment requires installing Unreal Engine 5.8+, Claude Code, and enabling the Unreal MCP plugin along with Python editor script plugins to allow the AI agent to interact with the scene. [00:03:19](https://www.youtube.com/watch?v=v-6KM2ysQYo&t=199)
- Using planning mode allows the AI to research game mechanics and design a detailed vertical slice of a GTA-style game, including character switching, wanted levels, and specific environmental aesthetics like sunset neon. [00:09:10](https://www.youtube.com/watch?v=v-6KM2ysQYo&t=550)
- The workflow integrates free assets from Epic's Fab marketplace and built-in feature packs, with the AI agent handling the import and placement of characters, vehicles, and environmental details to build the game world. [00:12:18](https://www.youtube.com/watch?v=v-6KM2ysQYo&t=738)
- The creator concludes that while the current MCP implementation is synchronous and slow, it significantly empowers solo developers by automating trivial tasks, allowing them to focus on high-level creative direction.
