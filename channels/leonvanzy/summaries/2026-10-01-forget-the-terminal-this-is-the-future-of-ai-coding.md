# Forget the Terminal. This Is the Future of AI Coding

## Executive Summary

Leon van Zyl presents a 3D, gamified interface for managing AI coding agents, replacing traditional terminal or web-based tools. The system features a CEO agent that coordinates sub-agents across projects, integrates with GitHub for issue tracking and pull requests, and includes a mobile app for remote interaction. Built almost entirely with Opus 5.5 in about 76 minutes for $35, the project is open-source and can be set up with a single command. The video demonstrates the full workflow, from hiring agents to previewing live website changes, and highlights the potential for making AI coding more accessible and engaging.

## Key Points

- The 3D software factory replaces traditional terminal or web interfaces, offering a visual and interactive way to manage coding agents, with a CEO agent as the primary point of contact. [00:00:00](https://www.youtube.com/watch?v=NBZmxhcz5lo&t=0)
- The system integrates with GitHub, automatically creating issues and pull requests, with a QA agent reviewing changes and auto-merging once all checks pass. [07:16](https://www.youtube.com/watch?v=NBZmxhcz5lo&t=436)
- The entire project was built using Opus 5.5 in about 1 hour and 16 minutes for only $35, and it is open-source with a one-command setup. [12:29](https://www.youtube.com/watch?v=NBZmxhcz5lo&t=749)
