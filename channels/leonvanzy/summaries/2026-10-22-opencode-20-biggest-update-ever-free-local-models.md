# OpenCode 2.0: Biggest Update Ever (Free + Local Models)

## Executive Summary

OpenCode 2.0 introduces cross-platform session continuity, background agents, code mode for efficient tool execution, work trees for safe code changes, plugin creation, and built-in free models, with optional local model support via Ollama. The update emphasizes flexibility and cost-effectiveness, allowing users to build apps without spending money, while cautioning about data usage for free tiers. The video demonstrates building a bill-sharing app, showcasing features like subagents, code mode, work trees, and plugin security.

## Key Points

- OpenCode 2.0 syncs sessions across terminal, desktop, and mobile, and supports background agents and subagents. [00:00:00](https://www.youtube.com/watch?v=OyuId4YQiIs&t=0)
- Code mode lets agents run multiple tool calls via a script, reducing context window overload. [00:08:13](https://www.youtube.com/watch?v=OyuId4YQiIs&t=493)
- Work trees create a copy of the codebase for safe changes, which can be merged back to master. [00:09:19](https://www.youtube.com/watch?v=OyuId4YQiIs&t=559)
- Agents can write plugins (e.g., to block .env file access) and local models can be run via Ollama. [00:10:33](https://www.youtube.com/watch?v=OyuId4YQiIs&t=633)
