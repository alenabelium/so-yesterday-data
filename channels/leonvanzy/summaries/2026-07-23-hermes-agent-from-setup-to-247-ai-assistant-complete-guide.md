# Hermes Agent: From Setup to 24/7 AI Assistant (Complete Guide)

## Executive Summary

This video provides a comprehensive guide to setting up Hermes Agent, transforming it from a local tool into a persistent, 24/7 AI assistant accessible via web and mobile. The tutorial covers installing the desktop app, connecting various LLM providers like OpenAI and local Ollama models, and configuring messaging integrations such as Telegram. By deploying the agent on a Virtual Private Server (VPS), users can ensure continuous operation and synchronize their local desktop interface with the remote instance for seamless access.

## Key Points

- Hermes Agent offers flexible setup options via terminal or desktop app, supporting diverse LLM providers including OpenAI, Anthropic, and local models via Ollama custom endpoints [00:03:50](https://www.youtube.com/watch?v=RnxXr_2ix3k&t=230).
- The desktop application allows users to connect to cloud providers like OpenAI through OAuth, enabling features like file system access, integrated terminals, and skill management [00:07:47](https://www.youtube.com/watch?v=RnxXr_2ix3k&t=467).
- Deploying Hermes Agent on a VPS ensures 24/7 uptime, providing a public web interface and allowing the agent to run scheduled tasks like cron jobs independently of local hardware [00:15:12](https://www.youtube.com/watch?v=RnxXr_2ix3k&t=912).
- Users can synchronize their local Hermes Desktop app with the remote VPS instance by configuring the gateway settings, ensuring all chats, skills, and automations are synced across devices [00:21:31](https://www.youtube.com/watch?v=RnxXr_2ix3k&t=1291).
