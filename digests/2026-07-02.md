## 2. Shift from Compute Surplus to Context and Memory Scarcity

As compute power enters surplus, the industry bottleneck has shifted to memory and contextual data integration. Companies are racing to build 'harnesses' that securely access private user data (e.g., Apple's Siri integration, Anthropic's Claude Tag) rather than just improving raw model intelligence. This has led to a new competitive paradigm where utility is defined by the ability to operate within messy, permissioned organizational contexts.
