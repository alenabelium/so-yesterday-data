McKinsey forecasts $1 trillion in sales will flow through AI agents, forcing businesses to refactor internal data stacks from human-centric marketing copy into structured, queryable schemas. Companies failing to make their product attributes legible to autonomous agents risk becoming invisible to the next generation of commerce.

<!--detail
The McKinsey projection of $1 trillion in agent-mediated sales is less a forecast than a forcing function, compelling businesses to treat their data infrastructure as a customer-facing surface. The core shift is architectural: companies must move beyond bolting on chat interfaces or MCP servers and instead refactor internal stacks so that every product attribute—from material composition to warranty terms—exists as structured, queryable schema rather than prose buried in marketing copy. The video's sharpest provocation is that legacy anti-bot systems, designed to block scraping, now inadvertently block revenue, as autonomous agents require clean, legible data to evaluate complex trade-offs and execute transactions without human hand-holding.

The source material introduces a critical tension that practitioners should not gloss over: the difference between "agent-readable" and "agent-writable." While the video emphasizes read-side legibility—making tribal knowledge explicit in durable schemas—it gestures toward a deeper challenge. Agents that can transact will also need to write back: updating inventory, negotiating terms, or flagging exceptions. Most current refactoring efforts focus on the read path, leaving the write path dangerously ungoverned. The video hedges on whether existing API wrappers or MCP servers suffice, ultimately dismissing them as superficial if the underlying data remains unstructured.

For transformation leaders, the actionable implication is immediate and concrete: run an agent-based audit of your own product catalog before your competitors do. Test whether an AI can discover, evaluate, and complete a purchase on your platform without human intervention. Where it fails, you have found your visibility gap. This shifts the conversation from speculative AI strategy to measurable operational readiness—a benchmark executives can own today. The businesses that win will treat schema design not as an IT chore but as a competitive moat, converting tacit human knowledge into machine-trustworthy attributes before the $1 trillion wave arrives.

## 4. Self-Improving Code Agents with Automated Testing and Evaluation

Claude Code Skills now feature the ability to automatically build, test, and evaluate custom skills using blind A/B comparisons, allowing agents to optimize their own workflows without human intervention. This capability includes dynamic context injection and isolated session execution to reduce token waste and improve reliability.

<!--detail
The most significant shift in this update is not that Claude Code can write skills, but that it can now prove they work before they are ever deployed. The Skill Creator skill automates the entire lifecycle: it generates a custom skill, runs it against a baseline, and then conducts blind A/B evaluations to verify the new workflow actually outperforms default agent behavior. This turns skill development from a subjective craft into an empirical, self-correcting loop where the agent itself becomes the quality assurance engineer.

The video’s technical details, however, reveal a tension between optimization and oversight. Dynamic context injection preloads project data—file trees, git history—directly into the skill’s execution, which dramatically reduces token waste and latency. Yet this efficiency comes at a cost: the agent is now making decisions about what context matters before the user even asks a question. Similarly, the `context: fork` property runs heavy tasks in isolated sessions to keep the main conversation clean, but this creates a black box where the reasoning that produced a result is no longer visible in the primary thread. The video presents these as pure wins, but practitioners should recognize them as a trade-off between resource efficiency and auditability.

For organizations driving AI transformation, the actionable implication is profound: this is the first credible path toward self-maintaining agent workflows. Teams no longer need to hand-tune prompts or manually validate outputs—the system can iterate on its own skills and demonstrate measurable improvement. The strategic move is to establish evaluation harnesses early, using these blind A/B tests as the gate for any custom skill entering production. The risk is complacency: if the agent optimizes for its own test metrics, those metrics must be aligned with actual business outcomes, not just token savings or task completion. The technology removes the human from the loop, so the human must now design the loop itself.

This divergence highlights a critical strategic gap where energy constraints and supply chain dominance are becoming the primary determinants of global AI leadership.

This is not merely a matter of cheaper labor; it is the ability to iterate hardware designs, produce components, and assemble systems under one national industrial umbrella, creating a feedback loop that software-only economies cannot easily replicate.
