## 1. Lean's formalization revolution exposes hidden errors in published mathematics

Kevin Hartnett's book 'Proof in the Code' chronicles how Lean, an interactive theorem prover, is transforming mathematics by machine-checking proofs. Formalizing frontier mathematics has revealed that even Fields medalists' published theorems contain implicit assumptions or minor errors, signaling a shift toward AI-verified rigor in the field.

<!--detail
The quiet revolution unfolding in mathematics is not a new theorem but a new standard of proof. Kevin Hartnett’s *Proof in the Code* documents how Lean, an interactive theorem prover, is forcing the field to confront a uncomfortable truth: much of what mathematicians accept as rigorous is built on implicit assumptions. When researchers formalize frontier results—like perfectoid spaces—into Lean’s machine-checkable language, they consistently uncover minor errors or hidden hypotheses in published work, including theorems by Fields medalists. The machine does not judge the mathematics wrong; it exposes the gap between informal human reasoning and the exhaustive logical scaffolding that true rigor demands.

The source conversation reveals a productive tension rather than a triumphalist narrative. On one hand, Lean’s crowdsourced library, Mathlib, enables unprecedented collaboration and certainty, allowing mathematicians to build without manually re-verifying every dependency. On the other, the rise of AI tools like AlphaProof and auto-formalization introduces what Hartnett calls “understanding debt”—machine-generated proofs that are correct but opaque, raising questions about whether verification without comprehension constitutes mathematical knowledge. The disagreement is not about whether Lean works, but about what is lost when proofs become artifacts only machines can fully audit.

For practitioners driving AI transformation, this is a blueprint for institutionalizing verification. The lesson is that formal verification does not merely catch errors; it changes the epistemology of the field, forcing explicit articulation of assumptions that were previously tolerated. Organizations adopting AI for critical decision-making should treat Lean as a model: invest in shared, machine-checkable infrastructure, expect that “accepted” processes contain hidden flaws, and prepare for resistance from experts whose authority rests on informal mastery. The future is not human versus machine, but a hybrid workflow where intuition proposes and formal systems dispose—and the organizations that build that pipeline first will set the standard.

The deeper story, however, is about the bottleneck shifting from code production to human attention—Anthropic’s own infrastructure moves, like replacing Git with a faster "Scan" system and automating code review via "Antique," suggest they are optimizing for a world where machines write the bulk of the code and humans curate, supervise, and approve.
